# From approved render to publication

This example's video: https://youtu.be/fg2cV8sh3kY

The owner reviewed and approved the final master. A supplied video URL does not by itself verify public visibility, YouTube processing quality or copyright-check results.

Use this checklist with your own agent. Mark items only when observed; keep a release record with the master SHA-256, channel ID, video ID, watch URL, check results and publication time.

- [ ] Freeze the selected recording, timing and scene snapshot. Render and preserve the master.
- [ ] Check codecs, frame rate, complete decode, audio sync, transitions and credits. Have the owner watch and approve the actual file.
- [ ] Prepare title, description, attribution and upload-size thumbnails. Select an intentional title/thumbnail comparison if desired.
- [ ] Sign into YouTube Studio and verify the intended channel before uploading. Never repoint another project's account integration silently.
- [ ] Create → Upload videos; select the master. Enter details and correct audience, language, category and AI disclosure. Do not infer media licensing from the source code license.
- [ ] Review copyright/other checks. Save Private while processing; verify the intended resolution and frame rate in the uploaded copy.
- [ ] Publish or schedule only under the owner's authorization. Verify watch-page visibility and record the actual URL.
- [ ] Update the project page, branch READMEs and announcement draft with the real URL. Keep code review/merge and social posting separate from uploading.
- [ ] Record evidence and unresolved issues; passing checks are not creative approval.
