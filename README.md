# intro-v3 — video package

This branch is the file system of one video: the flagship channel
intro "Welcome — Let's Build It Together", board piece intro-v3,
shipped build v3 (published 2026-10-22).

**This package is PARTIAL — by design, and visibly.** Its
decisions layer is incomplete: the element level is fully
recorded (18/18), but no per-word decision record exists for this
piece, so the word layer ships as a named absence (0/160) with
its authoring task stated. A reader does not need the metrics to
learn this; it is the package's central open field.

The package is the deliverable alongside the video. It grows in
developmental order — metadata, transcript, decisions, audio,
scene, render — and this branch's git history is the video's
development history.

Opened in its full form 2026-10-26 under Hadi's migration
directive + all-31 ruling (the branch itself was seeded by the
all-31 sweep): every video gets its own branch and its own file
system; contents are assembled from the video's real production
records, committed in the order the layers are built, with the
original artifacts cited per layer. Nothing here is backdated;
provenance lives in the records each layer cites. Open fields
ship visibly open.

Stage: metadata layer landed. The transcript, decisions, audio,
scene and render layers follow in developmental order.
