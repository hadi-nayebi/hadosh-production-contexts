# Hadosh Production Contexts

## Build the software your project needs

This is the context behind **Who Owns the Toaster?**, a Hadosh Academy song and music video about who keeps the final say as technology evolves.

We built two personal dashboards around this one project. They are intentionally good-enough, project-specific software: useful while the work needs them, open to being changed, and free to be replaced. The goal is not a complete production platform.

Another creator can give this repository to their own agents as a working example, then build a different dashboard around a different project. Copy the patterns that help. Change the rest.

## Two public dashboard versions

| Version | What it helped us do | Start here |
|---|---|---|
| Song production | Develop context, lyrics and musical direction; compare recordings and settle on a song | [Dashboard and README](https://github.com/hadi-nayebi/hadosh-production-contexts/tree/song-production) |
| Video production | Refine word and rhythm anchors, plan illustrated scenes, animate and review the song's visual story | [Dashboard and README](https://github.com/hadi-nayebi/hadosh-production-contexts/tree/video-production) |

The branches are independent public snapshots. Read each README before running it. They share an Origin-derived foundation but preserve different stages of the work.

## Use it with your agent

Give your agent this repository link and say:

> Study this as an example of software customized around one creative project. Help me identify which workflows and patterns fit my project. Explain the choices, then build a separate good-enough dashboard around my needs. Preserve my source files, ask about creative decisions, and show me the result as we work.

The [adaptation guide](https://github.com/hadi-nayebi/hadosh-production-contexts/blob/video-production/START-HERE.md) goes further. You do not need to understand every file before asking your agent to walk you through it.

## What is here

Source code, branch-specific setup instructions, illustrated scene plans, selected working and alternate assets, and workflow explanations. The original soundtrack and stems are not bundled; use audio you have rights to use. Historical example timings are tied to their original recording, not to your future song.

Code is MIT licensed. Artwork and third-party logos have separate provenance and rights considerations explained in each branch's ASSETS.md. Private account state, secrets, feedback journals and private Git history are excluded.
