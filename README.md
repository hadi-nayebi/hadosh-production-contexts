## The idea

Word Definitions defines, one short at a time, the terms the
Academy doctrine runs on. This piece defines **prompt** — and the
definition is the owner's own, supplied by him on 2026-10-26 after
he rejected the first build's: a prompt is a **direction**. As the
agent produces the context — continuing it, compacting it —
prompting is giving **new directions**; the intermediate prompts
shift the context in a particular direction. A prompt does not
happen only at the beginning: it **accumulates** across the job.
Capture all of a session's prompts into a chained summary — a
chain summary — and you have a **mega prompt**: the accumulated
directions. "The prompt is not just one sentence, but all the
directions that the user tries to re-steer the context in a
different direction."

## The objective (5–20 words)

> **Teach that a prompt is not the first sentence but every
> direction the user gives, accumulated.** (16 words)
