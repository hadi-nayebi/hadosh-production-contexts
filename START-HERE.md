# Agent entry point

First read README.md, WORKFLOW.md and ASSETS.md. This is a worked example, not an instruction to recreate the same song.

Ask the new owner for the intended message, audience, lyric draft, musical direction, authorized audio files and desired output. Explain the chosen branch. Create a separate working branch/project and preserve the example.

Inventory the current code and dependencies. Run the build before proposing changes. Trace one complete passage through lyrics, exact recording identity, timing, scene plan, artwork, preview and export. Generalize only the pieces the new project needs.

Never reuse example timestamps for a different recording. Keep manual anchors and approvals separate from estimates. Label uncertainty. Keep media local unless the owner explicitly requests sharing. Never add credentials to Git.

Create an illustrated visual plan for each scene. Maintain a concise decision record distinguishing owner direction from your interpretation. Review camera transitions, asset alignment, readable words, beat motion and scene lifetimes in actual playback. Ask focused questions when the desired story is unclear.

A render is not a publication approval. Let the owner review the complete output, title, thumbnail and description before external publication. Work incrementally and leave a reproducible snapshot.
