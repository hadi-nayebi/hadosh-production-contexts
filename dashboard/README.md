# Production Board — Hadosh Academy / Earth One

This folder is the shared production dashboard for the channels' video pipeline: every piece in production appears as a card carrying its stage, its growing per-stage checklist, its OPEVC cycle and phase, whose move it is, and links to its script, audio, scene, and Studio/public versions. `index.html` is a single self-contained page rendered from `production-state.json` — the state file is the source of truth, and the board is regenerated from it (and this folder re-pushed) whenever a production job changes any item's state, so the page never drifts from the records. `design-log.md` documents the board's own design iterations. Feedback does not belong in issues or chat: each item's card links to its thread in this repository's **Discussions**, where Hadi leaves scores, verdicts, and comments that Archer reads back and applies as fixes.
