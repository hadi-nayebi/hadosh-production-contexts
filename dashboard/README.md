# Production Board — Hadosh Academy / Earth One

This folder is the shared production dashboard for the channels' video pipeline: every piece in production appears as a card carrying its stage, its growing per-stage checklist, its OPEVC cycle and phase, whose move it is, and links to its script, audio, scene, and Studio/public versions. `index.html` is a single self-contained page rendered from `production-state.json` — the state file is the source of truth, and the board is regenerated from it (and this folder re-pushed) whenever a production job changes any item's state, so the page never drifts from the records. `design-log.md` documents the board's own design iterations. Feedback does not belong in issues or chat: each item's Comment link opens this repository's **Discussions** new-thread composer with the item's title filled in — Hadi writes the first comment there (that starts the thread) with his scores, verdicts, and picks, and Archer reads the threads back and applies them as fixes. Nothing on the board creates threads; the site root of this branch redirects to `dashboard/`, where the board lives.
