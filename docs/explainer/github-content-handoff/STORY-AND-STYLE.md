# Narrative and visual direction

Audience: a curious non-technical viewer. Explain through guided discovery, familiar anchors, concrete questions and causal transitions. Preserve deliberate connectors such as processed, To understand the scale, Let me repeat, If, So and In this series when their role is still needed. Every phrase should earn its place; brevity alone is not the objective.

The conceptual ladder is words represented by numbers and directions → contextual next-token prediction/autocomplete → assistant training and role/instruction formatting → output vocabulary plus a harness executing tools → agents working with project files → guidance, memory and externally enforced hooks. In a short, teach only the steps needed for its point; supply missing context instead of assuming the viewer saw earlier chapters.

Use independent illustrated/chalk cutouts in a quiet void. Assets assemble to perform an explanation, resolve the idea and retire or transform into the next useful symbol. This is an animated scene, not a page of labels with voice-over. Each visual element, position, movement, timing and transition needs an intended viewer inference and an inspectable reason. One dominant focus; readable text; large directional arrowheads; measured label/image/arrow/caption clearance through transitions. A photograph is not the established default aesthetic.

Motion advances with the spoken clauses. Reusing a visual is useful when a new action changes what it teaches. Camera drift, pulsing dots and fades do not count as explanatory development. A purposeful reading or discovery hold is allowed, with a reason. Score presentation-to-motion quality separately from technical tests; no code pass establishes creative acceptance.

Keep exact speech separate from narration performance and visual timing. Pauses, stress and question/answer delivery matter. Do not narrate production annotations. Existing user-cloned audio is private and is absent from this handoff; obtain explicit authorization and an appropriate private workflow before any voice reuse or upload.

A/B proposals should differ in teaching route, framing, example or visual mechanism. Tiny synonym swaps are not useful experiments. Preserve factual uncertainty, processing/output distinctions, metaphor limits and approved meanings. Do not call an unfinished draft final.
