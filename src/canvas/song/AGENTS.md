# Song studio scope

Hadi authorized this separate Canvas branch on October 8, 2026. The song studio is a domain-specific
derivative; the inherited empty Origin contract does not prevent it. Keep cartoon files, Admin,
Feedback transport, hooks and authority boundaries intact.

Every artifact records its upstream revisions. Changing upstream context invalidates dependent
approval without deleting human edits. Provider packets are requests, never generated audio. No
network generation, spend or credentials without a real adapter. Source claims, draft lyrics and
approved work remain visibly distinct. Audio/image files stay local; JSON carries metadata, and
portable HTML embeds media only on explicit export. Import validates all fields before replacing
state. Keep export text safe as untrusted input.

Keep each stage in its own component and share explicit typed contracts. Browser fixtures must
assert song and retained cartoon paths separately when the default branch product changes. Music
takes retain both the lyric revision and musical direction; changing either prevents approval.

Browser media readiness must use a bounded wait with an explicit failure, never an unresolved
loadedmetadata promise; source loading failures must not hang the production verification cycle.

Song controls live in a reserved header band. Floating Admin/Feedback controls must not cover
workspace fields, playback text or lineage; verify their geometry in populated phone/desktop stages.

Represent instrumental passages as arrangement sections, never fake lyric lines. Separate spoken
setup, sung words, chants and music-only regions when analyzing a reference. ASR silence and visual
cuts alone do not prove an instrumental boundary. Preserve baseline and each requested lyric pass,
and carry the selected lyric/arrangement revision into the generation packet. Avoid continuous-vocal
defaults when the user requests breathing room.
