# SOA-01 — consolidation of record for the final text (phase 23)

The final text's consolidation lives at phase 20, in the
experiments home where its two parent candidates live:

**`experiments/ab-2026-10-26/merge-consolidation.md`** — the
owner's verdict recorded as the revision's reason (§0), the
per-line merge account (§1: source and why, for every line),
the double-claim test (§2), the editor pass (§3), and what
the merge does not change (§4). Its companion
**`experiments/ab-2026-10-26/transcript-merged.md`** carries
the text with its design note and pause map.

This pointer file exists so the transcript layer of record
names its own consolidation, per the branch's convention
(the phase-11 layer did the same with
`consolidation-causal.md`). The consolidation is not copied
here: one record, one home — the phase-20 file is the record;
promotion changed the text's status, not its history.
