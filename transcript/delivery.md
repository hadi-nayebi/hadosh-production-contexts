# SOA-01 — delivery record + pause map (FINAL MERGED BUILD, phase 23; starts locked at phase 21)

Delivery is the second stage of the two-stage transcript
model: the content settled at phase 20
(`experiments/ab-2026-10-26/merge-consolidation.md`); this
file sizes its timing. The map merges the two candidates'
maps joint by joint (each joint's source is named in the
phase-20 transcript record); both final programmes follow
THIS map — the voices share the map, never the timings.
