## Doctrine map (how the ruling is taught)

- **Two parts, the only count:** L4 states it on the old line's hammer rhythm ("Two
  parts. Always the same two."); no other number appears.
- **The LLM is a utility:** L5 "a utility, like electricity"; L6 — works *inside* the
  harness, operates it, expands it.
- **The harness is organic:** L7 "a living file system"; L12 "still growing."
- **Interior = contents, not parts:** L7 opens the harness ("inside it:"); L8–11 name
  the poster's interior four in poster order.
- **Canon glosses:** Files = "where its memory is written down"; Hooks = "automatic
  responses."
- **The fork, doctrinally asymmetrical on purpose:** L13 stands **the system** apart
  (apart-ness belongs to the whole system); L14 wears **the harness** (wearing happens
  at the harness — the digital cortex). Ownership is the one difference (L15).
