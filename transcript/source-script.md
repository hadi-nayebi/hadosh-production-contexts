## OBJECTIVE (catalogue, GROUNDED — the comparison standard)

> "Show a tool turns the model's words into real actions, only
> where permission allows." (14 words)

**One-sentence job (HS-09 anchor):** INTRODUCE "tool" by the
capability gap — the model writes, cannot act — then draw the
boundary against Skills by mechanism: a tool acts; a skill
guides.

## ⚠ THE RULING, EMBODIED — PROVISIONAL (replaces Action #28 / canon O-1)

i2 froze this script on canon item O-1, the undefined Skills-vs-
Tools boundary. Per Hadi's substantial-artifact rule (2026-10-24),
the bare question is withdrawn and the boundary now travels
INSIDE the piece as a proposal he can correct on the artifact:

**PROPOSED RULING — the boundary is the mechanism.** A **tool**
is a *connection* the model calls: it reaches outside the model
and **acts** in the world (proposed calls executed only as
permitted). A **skill** is *know-how the harness carries* — a
packaged way of working, held as durable files — that **never
acts itself; it guides** how the model works. Tools act. Skills
guide.

- **Record basis — DERIVED from Hadi's own library** (exhaustion
  search 2026-10-24; full trail in the job file). The library
  is *not* silent here — the vocabulary essay defines the skill
  explicitly:
  - *The Language of Agents* (vocabulary essay): "A **skill**
    is a **reusable package of instructions and supporting
    resources — like a recipe card** with its tools and
    examples." And its hierarchy: "a skill explains **how to
    perform** a review, **a script might calculate** the
    hashes" — the skill explains/guides; execution belongs to
    scripts and tools the runtime performs.
  - The Academy study's site-grounded candidate resolution
    (FINDINGS, restated in the content audit): "skills =
    reusable instruction+resource packages the agent selects;
    **tools = actions the model proposes and the runtime
    performs/permit-checks**." B1 states the tool side
    verbatim: the runtime "reads the model's proposed calls,
    and **carries out the permitted ones**."
  - Canon §1 Tools row — "the system's **connection to its
    environment**"; §3 ledger — Tools: "What the agent can
    reach and do in the world" (capability confined to the
    reach-and-act sense); Skills: a compartment inside the

    decided to work*" — know-how is durable, file-carried
    guidance.
  - L6's line is the plain-language form of the essay's
    definition: a package of instructions the system carries
    *guides* the model; it never *acts* — acting is what the

    Lesson 3's provisional Skills gloss ("what it can do") is
