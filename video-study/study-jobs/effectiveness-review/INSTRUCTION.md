## §3/§4 — Execute + Verify (the verdict act)
For each class, exactly one verdict, evidence attached:
- **USED** — consumption evidence exists and spot-checks confirm it. Cite the pulls.
- **USABLE-UNUSED** — the cold form works (this cycle's pull test, or the library's standing naive-use evidence) but consumption is zero or thin. The verdict names the clock: how long the class has stood unconsumed, and the date by which continued zero becomes CEREMONY evidence.
- **CEREMONY** — any of: consumption zero past the named clock · the cold-pull test fails (unusable form) · production counts grew while nothing about usability did · score deltas ground without named plateaus. The verdict prices the cause (wrong topics · bad indexing · no demand · unusable form · lane reporting inflating production over use) and routes a cure to the owning job on the lane board.
**Headline rule:** a CEREMONY verdict on any class leads the HQ report. Burying it is a deviation in this job's own register.
**Self-application:** if the previous cycle's verdicts produced no action anywhere (no cure filed, no board movement, no HQ response in the record), this cycle files that as a finding on this job itself, in the same verdict form.
**Execute discipline (phase-guard augmentation, 2026-11-14):** Execute follows the Plan's Execute checklist step by step — a step not on the checklist is either added to the plan record with its reason or not done; the verdict act does not improvise new evidence paths mid-cycle.
**Verify call points:** before the verdict set files, Verify fires, in order: mechanical guard 1 (counts re-count) · mechanical guard 2 (pull-evidence check) · **`guards/jev-verdict.md`** on the draft verdict report (deliverable class: the weekly verdict report / HQ report — the call fires on every cycle and its verdict is advisory input to the filing decision: applied, or set aside with the miss recorded in Condense; an applied REFUSE keeps the draft unfiled and the lane hears "no verdict this cycle" + the reason; the manual panel + mechanical guards run alongside, and a cycle in which the call did not fire prints INCOMPLETE, never as guarded) · mechanical guard 3 (self-edit quarantine census at close — any same-cycle write by this job into a judged face voids the verdict).
