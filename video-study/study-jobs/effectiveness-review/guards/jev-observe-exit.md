# Jev call — jev-observe-exit (effectiveness-review)

_Per-call definition from jev-call-template.md. Built 2026-11-14 (phase-guard augmentation pass 1). The Observe→Plan gate for a job whose entire product is a verdict: if the week's evidence base is thin, stale, or contaminated by the judge's own edits, every verdict downstream is unearned — so the working memory is judged before any verdict plan is allowed to form on it._

## 1. What it judges
- Deliverable / surface judged: the cycle's Observe working memory — the evidence table in RUN.md (per asset class: pulls counted, citations spot-checked, tier/score deltas read), the cold-pull test state, and the independence record for the cycle so far.
- OPEVC call point: effectiveness-review INSTRUCTION §1 Observe, gate out. The phase advances on the verdict's recorded disposition (applied, or set aside with reason — a set-aside is itself priced at the next firing of this call). An unfired call makes the cycle INCOMPLETE.

## 2. Instruction (the model's charge)
Judge whether this cycle's working memory can support a verdict plan for THIS job — the weekly effectiveness review whose sole question is utility (usable AND used). Price, in order:
(1) SOURCE COVERAGE — were the named Observe resources actually read firsthand this cycle (GROWTH.md · CONSUMPTION.md · TECHNIQUES.md + scores.md deltas · ASSETS.md · INDEX.md · VIEWS.md where it bears on findability · verdict-history.md · the prior cycle's RUN.md for the self-application leg), each with its read evidence in the evidence table — or are numbers carried from a prior cycle's report or the lane's own summaries? Carried numbers are this job's founding defect risk: §5 guard 4 exists because a GROWTH figure taken on trust is a finding, not evidence.
(2) CITATION VERIFICATION — CONSUMPTION.md rows are claims, not proof. For every pull the working memory intends to rely on, was at least one citing production Observe record actually opened and confirmed this cycle (INSTRUCTION §1 step 2: at least one citation spot-checked per cycle)? A pull counted but never opened is UNCHECKED.
(3) FRESHNESS + CLOCK — is the verdict clock stated honestly in the working memory (clock started 2026-11-13; elapsed window for this cycle named), so CEREMONY can neither be fired early on a young lane nor deferred forever? Is the founding baseline (all production, no consumption — production 34 · consumption 0 at founding) carried as baseline, not re-printed as this week's finding?
(4) COLD-PULL TEST STATE — is the test's state named: this cycle's production need chosen or still open, the fresh-reader arrangement identified (a reader with only the library surface), the 3-minute bar carried, and any prior test result cited with its date? "We will run a pull test" with no named need, no reader, and no bar is not a state.
(5) INDEPENDENCE INTEGRITY — this job judges but never edits the faces it judges. Does the working memory record zero writes by this job into INDEX / TECHNIQUES / ASSETS / GROWTH / CONSUMPTION so far this cycle (mechanical guard 3, self-edit quarantine)? Any write by the judge into a judged face in this cycle contaminates the evidence base: the cycle cannot verdict what it touched.
(6) GAPS + ROUTING — are missing faces, unread deltas, or unverifiable citations named as gaps in the evidence table, or silently absent? Owner-information needs: this job's verdicts are decidable from lane evidence alone — the working memory must state "owner information needed: none" explicitly, or name the exact item and its routing (via HQ, never a direct owner ask from this job). Codex in Observe: ABSENT BY DESIGN for this job (see guards.md) — no Codex receipt is expected; an HQ-routed ad-hoc review, if one exists, is cited as a source, and its absence is never scored as a gap.
Score 0–1 per dimension and classify defects. You judge the evidence base's warrant to support verdicts, never the lane's effort and never the verdicts themselves (jev-verdict owns those).

## 3. Context contract (masked view)
- FED: the cycle's evidence table (RUN.md §1 portion) · the working memory's source-read list with timestamps · CONSUMPTION.md rows relied on + the spot-check record (which citing records were opened, outcome) · the clock statement · the cold-pull test state note · the cycle's file-touch list for the independence check.
- NEVER FED: this job's draft verdict leanings or rationale prose · HQ's hopes for the lane · the lane jobs' self-summaries of their own consumption (the faces themselves are the evidence; summaries of them are exactly what §1 forbids substituting) · prior cycles' jev-observe-exit profiles (each cycle's base priced on its own reads).
- Context ceiling: ≤32,000 tokens of text. Packing rule: the evidence table and spot-check record are fed whole; library faces are fed as the counted excerpts the table cites, never whole-file dumps; if the packet still exceeds the ceiling, the call fails preflight — it never truncates silently.

## 4. Output space
- Verdict classes: **ADVANCE** (Plan may open) · **ADVANCE-WITH-GAPS** (Plan opens; every gap named here is carried into the Plan as a priced limitation the verdicts must respect — e.g. a class whose citations could not be spot-checked may not print USED this cycle) · **RETURN-TO-OBSERVE** (the base cannot support verdicts; Observe re-runs).
- Dimensional scores (0–1): source coverage · citation verification · freshness + clock honesty · cold-pull test readiness · independence integrity · gap explicitness. (1.0 = every named source read firsthand this cycle with evidence / every relied-on pull spot-checked / clock + window stated exactly / test need + reader + bar all named / zero judge-writes into judged faces, censused / every gap printed. 0.0 = the opposite pole on each.)
- Rejection classification (one primary, on RETURN-TO-OBSERVE; secondary findings may name passage + evidence): STALE-FACE (a number or state carried from a prior report instead of re-read/re-counted this cycle) · UNCHECKED-CITATION (a relied-on CONSUMPTION row whose citing record was never opened) · MISSING-FACE (a named Observe resource unread, with no gap printed) · INDEPENDENCE-BREACH (this job wrote into a judged face this cycle) · CLOCK-UNSTATED (no clock start / elapsed window in the working memory) · PULL-TEST-UNNAMED (cold-pull state absent: no need, no reader, no bar).
- Accepted profiles travel: the profile files in RUN.md beside the evidence table; ADVANCE-WITH-GAPS limitations bind the Plan and are re-checked by jev-plan-exit.

## 5. Floors and disposition
- INDEPENDENCE-BREACH at any score → RETURN-TO-OBSERVE (the contaminated face's evidence is void this cycle; the breach is recorded, not repaired by this job — repairing it would be a second edit).
- independence integrity < 1.0 → RETURN-TO-OBSERVE. (The quarantine is binary by design; a partial quarantine is no quarantine.)
- source coverage < 0.5 or citation verification < 0.5 → RETURN-TO-OBSERVE.
- CLOCK-UNSTATED → at best ADVANCE-WITH-GAPS, with the clock statement as the named gap; a second consecutive cycle with the clock unstated → RETURN-TO-OBSERVE.
- Disposition: the verdict is advisory — reviewed by the runner, applied or set aside with the miss recorded in Condense. The verdict + primary classification + disposition land in RUN.md + verdict-history's cycle block either way; the cycle does not proceed on hope.

## Call command
- Assemble the §3 context packet (text only, ≤32k, preflight-checked) and fire this file's §2 instruction against it via the fleet's sealed decision-model route — the same transport jev-verdict binds to; until that binding lands, the call is executed as this defined prompt + context assembly by the cycle runner and its receipt (packet identity · definition version · validated output · disposition) is filed in RUN.md. Malformed output = PROTOCOL FAILURE, recorded as a RETURN-TO-OBSERVE disposition, never an improvised verdict.
- Firing: this call fires at its step on every cycle. A cycle in which it did not fire prints INCOMPLETE.

## 6. Firing record and improvement
- Exemplars: (a) the founding baseline record (runs/2026-11-13-cycle-001-founding/RUN.md — faces read firsthand, consumption 0 printed as zero, clock started 2026-11-13 stated, verdicts deferred by design) must receive ADVANCE or ADVANCE-WITH-GAPS (its lawful gap: no pull citations exist yet to spot-check). (b) A constructed working memory that counts a CONSUMPTION pull toward a USED-leaning evidence table without opening its citing Observe record must receive RETURN-TO-OBSERVE / UNCHECKED-CITATION. (c) A constructed working memory whose cycle file-touch list shows a write into GROWTH.md by this job must receive RETURN-TO-OBSERVE / INDEPENDENCE-BREACH at any other score.
- Firing: this call fires at its step on every cycle; its firing record and misses are its improvement material. No test precedes firing. The exemplars above stand as its first firing cases — all three must classify correctly when fired, and a miss is recorded in Condense as improvement material, never as a bar to firing.

## 7. Iteration (Condense)
This file is one of the four layers Condense iterates. Every amendment names: the evidence that forced it (a verdict later reversed for a base defect this gate passed · a gap this gate missed) · before/after. A text change takes effect on the call's next firing; the call keeps firing every cycle, and Condense prices the change against the returns that follow it.
