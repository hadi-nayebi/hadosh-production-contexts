## The review
Five independent lens runs re-score a re-attempt against the BAR: **average ≥ 85 AND no lens < 70**. Lenses: motion fidelity · timing/tempo · construction purity · reusability · **readability** (owner's fifth lens, 2026-11-14).

## Feeding contract (practice-specific terms)
- ONE stream per lens run (fleet rule): the ALLOWED PACKET only — lens instruction + neutral technique facts + the NEW recreation.html + the SCORE-BLIND build record (practice INSTRUCTION E4c, as amended Cycle-002 on Codex Condense finding 6). **scores.md is NEVER in a lens payload** — it is the seat's filing target; prior scores/verdicts/targets live only in the seat's tasking. Lens instructions open with the standing header (consumer + decision priced · working record · BODY-WRITE line) and end with `SCORE: <integer>`.
- **Final-source binding (A-C002-4, strengthened Cycle-002 on Codex Condense finding 5): all five returns of an attempt must judge the IDENTICAL final artifact — the final recreation.html sha256 is recorded in the build record / run record, and any lens fired against an interim source is re-fired against the final source with its prefix return preserved; a stale return never files as a final score.**
- **Prior scores are NAMED in the seat's tasking, never fed as anchors inside a lens run** — a lens prices the build in front of it; the delta is the seat's arithmetic (mechanical guard 1), not a lens's impression. Cross-instrument note: when the prior attempt was scored under a different lens count (T15 attempt 1: four lenses), deltas print both counts and read as instrument-changed.
- Returns file VERBATIM in the artifact's `codex/` (attempt-tagged); scores.md cites them.

## Consumer
- Consumer: practice's §5 Verify (delta + floor rule) + recreation (tier recommendation moves only on a passing re-score) + the artifact's scores.md (the permanent delta record).
- Decision priced: whether the re-attempt beats its predecessor, whether the item leaves the pool (pass), and — on a non-beating score — whether the WHY names a real plateau (jev-plateau).
