## 4. Cure plan (convergent first — Amendment A1)

### C1 — CONVERGENT 1 (timing 78 + reuse 72) · Counter lifecycle / absolute timeline · PRIMARY
Construction changes:
- Replace the nested relative `setTimeout` chain (`cycle()` whip recursion + `scheduleStamp()` + `play()` loop timer) with ONE absolute timeline: `t0` captured at play; a scheduler (rAF or single timer) computes `elapsed = now − t0`, `phase = elapsed % loopMs`, and fires checkpoints from a CONFIG-held event table (card starts, whip midpoints, counter starts, checks-ready, stamp, hide, loop). No event is scheduled relative to another event's callback.
- Counter cancellation: `animateCounter` stores its own rAF id + a generation token incremented on every card start; starting a counter FIRST `cancelAnimationFrame`s the previous counter's id, and a stale tick whose token ≠ current generation no-ops even if cancellation is missed. Pause/restart cancel counter + scheduler together (existing `clearTimers` discipline retained and extended to the scheduler).
- Loop-boundary law: the event table contains no card start at 9.1s (or any start whose counter crosses `loopMs`); the terminal sequence (C2) owns the tail of the loop. At the filed worst case `cardMs=900` the counter span derives from the card span (A-C006-4: effective counter duration = min(counterMs, cardIntervalMs − whipSettleMs)); an invalid combination (counter span ≤0) is rejected atomically (timeline unchanged) and recorded in an observable rejected-overrides list the own-check suite can assert.
Own-checks (effect, not counts):
- A-C002-1 timeline simulation: drive the event-table logic headlessly at default AND `cardMs=900`; assert (a) zero overlapping counter intervals, (b) every counter interval ends ≤ its card's successor event and ≤ loopMs, (c) generation-token test — starting counter B while A is mid-flight leaves exactly one live counter and A's tick produces no DOM write.
- A-C006-1 invariant assert: the §3 C-4 inequalities hold for the shipped event table, computed from CONFIG, not literals.
