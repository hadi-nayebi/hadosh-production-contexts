C1 is single-lens (motion) but is the largest single motion deduction mechanism (opacity²) and is a one-branch construction change.

- **C1 — Parent-only entrance opacity** (motion 74; attempt-2 motion return finding 1). Defect in source: `renderAt` unit branch sets `cardEl.style.opacity = vis` AND every `.qline` / `#chip` / `#glyph` opacity = `vis`, so content's effective opacity is vis² and emerges slower than the panel. Construction change: in unit mode the parent `#card` alone carries entrance/exit opacity; child opacities are set to 1 (or not assigned) in that branch. The staggered branch keeps its per-line semantics but must not multiply against a parent that is also fading the same lines — staggered parent opacity carries exit only, entrance stays child-driven (state which in the build record). Own-check (A-C008-2, plan-stated surface): at half-entrance, DISPLAYED effective opacity (parent × child) of glyph, a quote line, and the attribution each EQUALS the entrance progress, not its square.
- **C2 — Entrance/exit intervals constrained to the sampled states** (timing 80; attempt-2 timing return, all five findings). Construction change: replace the single global entrance span (`cardEnterMs` 500 applied from `startAtMs`) with per-quote interval fields in CONFIG — entrance interval start + duration per quote (e.g. `enterAtMs`/`enterDurMs`, or an explicit interval pair) — bound to satisfy EVERY row of the anchor table: card 1 entrance interval inside (0, 1000] with opacity(500) strictly partial and first-complete at 1000; card 1 exit interval starting ≥8000, still partial at 8500, complete by 9000; card 2 entrance interval starting in [11000, 11500) so opacity(11000)=0, opacity(11500) faint-partial, first-complete at 12500. Sequence/staggered span derivation must consume the same per-quote durations (rides with C6). Own-checks assert the displayed state at 0 / 500 / 1000 / 8000 / 8500 / 9000 / 11000 / 11500 / 12500 / 14000 ms exactly as the table states.
- **C3 — Scene-linked zoom-out exit + second card's lower-left entrance** (motion 74; attempt-2 motion findings 2–3). Construction changes: (1) exit is no longer a constant-scale fade — exit progress drives a CONFIG-parameterized scene-linked transform (`exitScaleTo` + exit fade) so the card visibly exits WITH a zooming scene; direction/magnitude are one-key reversible because the segment wording ("scene zoom-out transition; the card exits with the scene") does not fix the card's scale sign at 0.5 s sampling — Execute states its reading in the build record and prices the residual in the WHY scaffold.
