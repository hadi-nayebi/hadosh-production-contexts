# Codex review — codex-condense (practice)

_Repeated Codex review type, defined in this job's own guards layer (phase-guard augmentation, 2026-11-14). Practice's Condense is where a cure that moved its lens becomes a standing construction note for the recreation job, and where this job's own guards learn — both are faithfulness claims about what the cycle actually proved, and both are attackable._

## Standing header (every firing carries it)
1. Consumer: the job's NEXT cycle (its Observe reads the amended INSTRUCTION + guards as its starting law) — and, for construction-note hand-offs, the recreation job via its board.
2. Decision priced: whether the cycle's lessons, as applied to the instruction layer, actually encode what the attempt's evidence showed — or whether Condense promoted a coincidence, a single-lens movement, or an effort narrative into law.
3. Working record: the cycle's RUN.md (Condense section + faithfulness trace) and the files the Condense amended.
4. Body-write: the return files verbatim in the cycle's run directory (`runs/<date>-cycle-<NNN>-wave-<K>/codex-condense-return.md`); a finding that an amendment overclaims forces the amendment's regrade (demonstrated → candidate, or struck) in the same cycle, printed in RUN.md. A return naming no body-write is incomplete.

## The review (instruction to Codex)
Attack this practice cycle's Condense: its lessons and the instruction-layer amendments they produced. The question is never whether the lessons sound plausible — it is whether THIS attempt's filed evidence carries them.
- EVIDENCE ATTACK: for each promoted lesson, name the filed evidence (lens returns, delta arithmetic, own-checks) that demonstrates it. Practice's standing promotion rule: a cure that moved its lens TWICE becomes a standing construction note — attack any note promoted on one movement, any "demonstrated" label whose second instance is the same attempt recounted, and any lesson whose evidence is the builder's narrative rather than a filed return.
- LAYER-ESCAPE ATTACK: the Condense must iterate FOUR layers — (1) INSTRUCTION steps, (2) mechanical guard code/procedures (guards.md guards 1–3), (3) Jev definitions (jev-plateau · jev-observe-exit · jev-plan-exit), (4) Codex prompts (codex-rescore-wave · codex-observe · codex-plan-review · this file). For each layer, the cycle either amended it or proved it with a NO-DEFECT finding naming the evidence checked. List every layer that escaped review, and every NO-DEFECT claim whose named evidence does not check it.
- PLATEAU-LESSON ATTACK: if the cycle filed a WHY / plateau, attack the lesson drawn from it: does the amendment change the construction approach the plateau actually indicted, or does it merely record the plateau and re-aim nothing? Cross-check against the jev-plateau verdict/profile filed in scores.md.
- HAND-OFF ATTACK: any construction note handed to the recreation job — is it stated as a construction rule a first-attempt builder can apply cold (parameterized, config-level), or is it a story about this attempt? A note recreation cannot consume is ceremony, and this review names it as such.
- DIVERGENCE ATTACK: practice's wave definition (`codex-rescore-wave.md`) matches recreation's by design but lives here — if this Condense amended any shared-form file (wave definition, bar, lens set), is the divergence printed in BOTH files, as guards.md requires?
Close with exactly one verdict line: `CONDENSE: FAITHFUL` or `CONDENSE: REGRADE BEFORE CLOSE` followed by the numbered findings.
