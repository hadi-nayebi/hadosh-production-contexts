### C3 — Capacity consequences (residual 3 · CONVERGENT — reusability 70 + readability 79)

**Defects as filed (source-confirmed):** (a) `render()` draws the marquee with `fillText` centred at `hx + hw/2` with **no clip** — an over-capacity marquee draws at full width past its strip; (b) `render()` never reads `sampled.fitStatus` — the facade renders identically whether fit succeeded or reported over-capacity; (c) the reusability return's sub-finding: `sampleFacade`'s fit loop, on reaching the floor by a jump (`fontPx !== sampleMinFontPx` → set to floor, re-draw), sets `fitStatus = "over-capacity"` **without re-measuring at the floor** — a floor fit that actually fits is misreported (marqueeFit already re-measures at its floor; the facade path does not).

### C4 — Vertical fit against the full line region (residual 4 · reusability 70)

**Defect as filed (source-confirmed):** in `drawAndMeasure`, each line's ink rows are scanned only inside `y ∈ [lineH·li, lineH·(li+1))` — ink height is counted inside the band it must fit, so a glyph clipped by or crossing the band **cannot fail** the height axis (`heightOk` compares a band-capped number against the band).
**Construction change:** measure before banding. `drawAndMeasure` gains a per-line **full-region ink extent**: for each line, scan the whole sample canvas height and attribute each ink row to the line whose band centre is nearest that row (ties to the upper line — rule printed in the build record); record `inkTopPx / inkBottomPx / inkExtentPx` per line from that unbanded scan. The fit test's height axis becomes: for every line, `inkExtentPx ≤ bandHeightPx` **AND** `inkTopPx ≥ band top` **AND** `inkBottomPx < band bottom` — extent and placement both priced, against the full region. The existing in-band `inkHeightPx` stays as a reported row (the fit table prints both, so the a2→a3 measurement change is visible, A-C010-3-style: both bases printed, the new basis governing).
**Assertions:** a constructed case that a2's logic passes and a3's must fail — a stub glyph whose ink extent exceeds its band (tall-glyph stub / reduced `sampleH` per line count) asserts `bindingAxis: "height"` and a font step-down or over-capacity at the floor; the default specimen's per-line extents print in fit-table-attempt3 (expected well inside bands — if the default specimen fails the new axis, that is a premise event under failure point F2, not a ship-through).
