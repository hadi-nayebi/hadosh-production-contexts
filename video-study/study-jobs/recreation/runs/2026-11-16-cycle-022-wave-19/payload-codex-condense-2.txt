## Standing header (every run opens with it)
1. **Consumer:** recreation's §9 Condense for the closing cycle + the decision priced: whether the cycle's lessons were faithfully encoded into the instruction layer (steps · mechanical guards · Jev definitions · Codex prompts), or whether an amendment claims a lesson its text does not carry.
2. **Working record:** the cycle's RUN.md (traces + returns) + INSTRUCTION.md as amended this Condense + guards/ as amended this Condense + verdict-history.md — the run builds from the cycle record and the amended files, and writes its return into the cycle record's Condense section.
3. **Body-write:** the return must end with a `BODY-WRITE:` line naming what it filed; a read-only run closes with "Body-write: none (read-only run)" and the consumer (the cycle record) persists the return verbatim.

## The review
Fires at §9 Condense close, after the cycle's amendments are drafted and before the cycle record closes. The run attacks:
- **Faithfulness of each amendment:** for every lesson promoted this cycle (dated, technique cited — §9 form), does the amended instruction/guard text actually encode the lesson such that a cold builder following only the text would behave differently? An amendment that names a cure in prose while leaving the operative step unchanged is classified AMENDMENT-THEATRE. Founding calibration shape: Amendment A5 — Owner Cures 1+2 landed as construction requirements AND a fifth lens in §5.4 AND flow-field guidance; a lesser encoding (a mention in a lessons list) would have failed this attack.
- **Four-layer coverage:** did this cycle's experience touch each layer — (1) instruction steps, (2) mechanical guard code/commands (guards.md), (3) Jev definitions (jev-prewave · jev-observe-exit · jev-plan-exit), (4) Codex prompts (codex-scoring-wave · codex-observe · codex-plan-review · this file) — and for each untouched layer, is the no-change a NO-DEFECT proof naming the evidence checked, or an escape? A reversed verdict, a defect that passed a gate, or a lens finding that recurred across two techniques (§9 pattern rule) MUST land on its owning layer or be named not-yet-amended with reason (the presence-evaluation rule).
- **Score-evidence binding:** every lesson citing a lens score cites the filed return (artifact codex/ path); a lesson priced from the seat's summary rather than the return is named.
- **Wave re-pricing honesty (§0):** if this cycle re-priced wave size or cadence, the return checks the re-price cites measured per-item cost from THIS cycle's filings — a re-price from expectation is attacked.
The run does not re-score recreations and does not edit files; its REVISE verdict returns the named amendment to Condense for re-encoding before the cycle closes.
