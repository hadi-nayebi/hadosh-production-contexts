### 2.3 Construction choice
One self-contained HTML file. DOM: per-letter spans inside per-word wrappers inside one mounted chunk container; a single rAF clock. Per frame, per word: visual progress `p = clamp((tRel − onsetRel) / ((endRel − onsetRel) × sweepFraction))`; per letter `fill = clamp((p × letterCount − letterIndex) / frontSoftnessLetters + (letterIndex < p × letterCount − frontSoftnessLetters ? 1 : 0))` — equivalently a front at `p × letterCount` with a soft band of `frontSoftnessLetters`; `color = lerp(unspokenColor, spokenColor, fill)`. **Lift ownership (plan-review finding 2, applied):** the phase machine owns lift per word — lift rises over `liftRiseMs` from the word's onset (lift LEADS color, per census f-46.1), holds while the word's visual fill < 1, and settles over `liftSettleMs` after visual fill reaches 1; a later word's onset never cancels an earlier word's settle — envelopes are per-word and independent, so source state and tests agree by construction. **Intensity separation as construction (finding 2):** at any instant at most one word per chunk has 0 < fill < 1 (sweeps are sequential and non-overlapping in the schedule); the completed prefix renders exactly `spokenColor`, the unspoken suffix exactly `unspokenColor`, and the transition region is confined to the active word's soft front — separation is a state invariant, asserted in Verify at phone width by reading DOM state (exact endpoint colors), not by eyeball. **Chunk exclusivity (Owner Cure 2 form):** exactly one chunk is mounted at a time (cut at chunk start = first word onset) — phrase exclusivity is structural, not arithmetic. A5 flow-field guidance priced **NOT APPLICABLE** (no particle pool; the two-state color system IS the intensity separation). Label card: separate CONFIG block rendering before L1, dissolve approximated by opacity+pixel-block fade — named approximation, outside the core engine.
**Rejected alternatives:** CSS keyframes per word — the 17-word onset/duration schedule would hardcode into CSS, failing parameterization/A9.6 · canvas text rendering — DOM gives layout, wrapping, phone scaling and per-letter color without glyph measurement; canvas is the fallback only if DOM perf fails · per-word `background-clip:text` gradient — still needs the JS clock for the schedule and cannot carry the per-word lift as cleanly; spans subsume it · video/frame-sequence of the original — refusal-class (§6.1).

## §1 Observe

### Mechanics (the trick)
A visibility-state system. Every word of a demonstration card is **present and visible in the UNSPOKEN state** (white, full opacity, baseline size/weight) **from the card's first frame**; at each word's spoken onset **only its state changes** (here white → spoken yellow). Nothing appears at onset; no word is created, moved, or resized at onset. Anticipation is a visibility state, not a reveal — the reader can pre-read the whole line while the state change still marks the voice's position. The onset state changes are the motion (TECHNIQUES.md register, line 139).

### The T195 distinction (required, stated plainly)
Sibling T195 (same packet, this same wave, no scores yet) is the sweep's **color-state flip**: its subject is the change itself — white→yellow per word at spoken onset, sweeping at letter scale. **T196 is the visibility contract**: its subject is what is true *before* any change — the whole line present from the start in its unspoken state; only state changes at onset. A build that renders words progressively but flips them on time could satisfy T195 and would FAIL T196. T196's scored invariant: word-node count, visibility, and geometry are constant across every onset; only state classes change. The recreation's assertion suite (A11 map below) tests presence, not flip color.

### Construction choice (revised)
**DOM word spans + one rAF clock + one stage slot.** ALL cards' spans are **prebuilt** at load (hidden); the stage slot shows exactly one card per half-open interval with **atomic handoff** (at a boundary instant: incoming card complete + visible, outgoing spans zero visible — asserted). State is a pure function of the timestamp — `state(word, t) = spoken iff word.onsetMs < t` (tie rule explicit) — so playback, seek, and restart derive identical states from the same t (cure 2). Entry states are computed from onsets, never stored. Stage box size is reserved before first paint (T03 readability cure: no layout shift). Rejected alternatives: typing/textContent append (T03's construction — IS the reveal T196 negates) · per-word CSS keyframes (timing in CSS, not CONFIG — A9.6 failure) · canvas + runtime text sampling (A1.2 precedent — lawful for formation techniques; here no formation exists, only state, so it adds a purity-priced surface for zero mechanic) · `<video>`/`<img>` of specimen (refusal class §6.1).
