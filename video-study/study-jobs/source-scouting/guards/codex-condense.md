# Codex instruction — codex-condense (source-scouting)

_Standing header (fleet Codex rule): (1) Consumer: this job's next cycle (its §1 Observe inherits the amended layer). (2) Decision priced: whether the cycle's lessons were faithfully encoded into the instruction layer — or merely narrated in the run record while the layer stands unchanged. (3) Working record: the cycle's RUN.md + this job's INSTRUCTION.md + guards/ — amendments land only through the job's own Condense (§9), with this return consumed into the cycle record. (4) Body-write: the return must name what it wrote into the body (each amendment it forced or confirmed, by file and section); a return naming no body-write is incomplete._

## The run's charge
Review the closing cycle's Condense. Fed (embedded in the single stream): the cycle's RUN.md incl. its faithfulness trace + candidate lessons · the Condense's proposed/promoted amendments as diffs or before/after excerpts · verdict-history.md · the current INSTRUCTION.md sections the amendments touch (§1 Observe · §2 Plan · §6 guards · §9 Condense) · the guards/ files amended this cycle, if any.

Attack, in order:
1. **Lesson→amendment faithfulness** — for each promoted lesson (source-yield evidence · reason forms that predicted useful packets · a guard verdict reversed or a defect that passed), does the amendment's text actually encode it, in the section a future cycle will read at the moment it matters? A lesson promoted into §9 prose that should have changed §1's resource list or §2's mix law is an escape, named.
2. **Layer escape** — which of the four layers (instruction steps · mechanical guard commands · Jev definitions · Codex instructions) did this cycle's experience touch but Condense leave unreviewed? Each unreviewed-but-touched layer is named; "no change needed" is lawful only with the evidence checked printed beside it.
3. **Source-yield accounting** — does the yield record support the mix the amended §2 now prescribes, including §9's three-zero-yield demotion applied or explicitly not-yet-due?
4. **Guard growth** — did any Jev/Codex definition earn an amendment from its fired verdicts this cycle (a misclassification, a floor that passed a defect)? If no guard fired this cycle, the return prices that absence itself: a Condense over unfired guards can improve steps, never judges.
5. **Territory-to-admission drift** (added Cycle-006 Condense, 2026-11-16 — this check's own first firing caught the founding instance) — for every admission, compare the candidate's demonstrated mechanic against its territory's target shape AS WRITTEN in the approved Plan. A candidate admitted on a broader reading of its territory than the Plan states is a drift: name it, and check the run record prices it as one (deviation register + re-priced success) rather than as the territory met. A cycle whose admissions all match their territories prints that as a checked negative.

## Feeding contract
One stream only (`cat instr.txt artifacts… | codex exec -`, no stdin field). Reasoning-only returns verify at source level and say so. The run writes nothing itself; the consumer (this job's Condense) persists the return into the cycle record verbatim.
