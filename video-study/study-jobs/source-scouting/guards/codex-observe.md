_Standing header (fleet Codex rule): (1) Consumer: this sweep's Plan step (§2) — the run's own next phase, named in RUN.md. (2) Decision priced: which territories and creator lines are genuinely novel-and-adjacent enough to spend this sweep's searches on, vs already digested, already queued, or generic. ## The run's charge
Audit this job's Observe record before Plan prices it. Fed (embedded in the single stream, never a path the run must fetch): the current QUEUE.md (live entries + digested table) · the style library INDEX technique/creator names · the study notes' named creators/styles (`hidden_files/study/notes/` + CURRICULUM excerpts) · the production adjacency excerpts Observe read (DLC lane's current containers · studio's current style work) · RUN.md's Observe draft.

Attack, in order:
1. **Duplication** — any creator, style line, or technique territory in the adjacency/notes material that is already digested or already queued, named with its collision. Scouting it again is this lane's purest waste.
2. **Adjacency reality** — is the claimed production adjacency real (a container or build that exists in the fed records and is actually next) or asserted? An adjacency claim with no fed record behind it prints UNVERIFIED.
3. **Novelty surface** — from the fed record only, name the adjacent territories NOT yet covered by the library (e.g. a container family with no transition-led specimen queued — the founding refill gap) as candidate territories for Plan, each with the record line that makes it adjacent.
4. **Owner-send sweep** — any owner-sent specimen visible in the fed lane-board excerpts that is not in QUEUE.md, named. (If no board excerpt was fed, print that limitation — never a clean bill.)
