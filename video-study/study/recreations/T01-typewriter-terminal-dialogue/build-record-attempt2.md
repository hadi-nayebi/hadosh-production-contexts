## §1 — What was built

The pre-existing build was preserved before any write as `recreation-attempt-1.html` (sha256 `bbc2017e05d75809d538baec9859d44ab0cadc2e7d89e1cfcb2b3b75a1fefd1a`, verified against the seat's preservation baseline before the copy and again after filing).

Construction, by subsystem:

- **Timeline (pure functions, DOM-free):** `buildTimeline(cfg)` sequences banner title → banner subline → dialogue lines. Dialogue tempo has two named phases in CONFIG: main lines type at `charMs` (35.5 ms); the closing exchange (last `finaleLines` = 2 lines) types at `finaleCharMs` (146 ms), preceded by `finaleStartPauseMs` (500 ms) and a `closingPauseMs` (2600 ms) before the final line. All pauses, the banner gap (`bannerGapMs` 60), the subline speed (`bannerSubCharMs` 12), and the dialogue start pause (`dialoguePauseMs` 212) are CONFIG keys.
- **Scroll (deterministic function of t):** `buildLayout(cfg, stageW, stageH, charWidthPx)` computes measured bounds for the actual stage size — banner height from its wrapped title/subline rows, per-line wrapped heights from a whole-word wrap model at the measured monospace character width (canvas-measured against the live font in the browser; 0.6 em nominal advance in logic tests), viewport height from the stage. `buildScrollKeyframes` precomputes one keyframe per scroll-target change (a line starting, a wrapped row appearing), timestamped one ease duration (`scrollEaseMs` 350) before the event that needs it; targets are monotonic (the log never scrolls back down). A dedicated banner-exit keyframe at the start of line `bannerExitLine` (CONFIG, default index 6) raises the target to the banner box's bottom edge, so the banner has fully left the viewport by that line. `scrollYAt(t)` eases between keyframe targets with a smoothstep. `stateAt(cfg, tl, layout, scroll, t)` is a pure function — no playback history is read, so a seek and continuous play produce identical state at the same t. Phase rates are consistent between the timeline and the render state: the subline is scheduled and revealed at `bannerSubCharMs`, the banner title at `bannerCharMs`, dialogue at each line's own rate.
- **Cursor:** after dialogue starts, `cursorTarget` is always the latest started line index; after the final line completes it remains the final line index through the end hold. Blink timing is CONFIG (`blinkPeriodMs` 1060, `blinkOnMs` 700).
- **Readability:** dialogue wraps whole-word (`overflow-wrap: break-word`; no `anywhere`). Font sizes are stage-relative via `effectiveSizes`: dialogue = `fontSizePx` scaled by stage width / `designWidthPx` (960), floored at `minDialoguePx` (19); chrome/status scale from `chromeFontPx` (15), floored at `minChromePx` (11.5). Secondary palette lightened: `statusText` `#a3a8ab`, `bannerSub` `#c4c8cb`.
- **Reuse / CONFIG hardening:** `validateConfig` runs at load (and after URL overrides): numeric timings/sizes are clamped to named ranges (`endHoldMs` clamps to ≤300 ms), a missing/empty `lines` array installs a one-line fallback with a warning, non-string line text is coerced, unknown speakers fall back to the user style with a warning. Speakers are a CONFIG map (`speakers: {user, ai, narrator}` — glyph + prompt color + text color per key; a third speaker is expressible by adding a key). Behavioral constants promoted to CONFIG: banner gap, subline speed, dialogue-start pause, finale pauses, blink timings, scroll ease/pad, layout geometry (chrome/status heights, paddings, line margin/gap, banner margin/max-width). `seekTo` and `restart` reset the frame clock (`lastTs = null`) so seeking during playback does not drift.
- **End hold:** `endHoldMs` = 200 ms, named here as loop padding — the interval between typing completion and `durationMs`; no other hold exists in the timeline.
