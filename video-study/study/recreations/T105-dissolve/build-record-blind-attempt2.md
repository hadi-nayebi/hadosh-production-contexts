## 1. Mechanics
One scene cross-fades into another over a short blend — both scenes coexist at partial rendered weight at the midpoint, then the incoming scene holds clean. The overlap duration is the technique; there is no midpoint hold in the specimen (measured in §3).

## 2. Construction
DOM, one self-contained file, CONFIG at top, logic reads only CONFIG. Two full-stage scene layers stacked (A beneath, B above). Compositing construction: layer A is held at DOM opacity 1 throughout; layer B's DOM opacity equals the shared progress value p. Because layer B's own field is an opaque full-stage field, source-over compositing gives rendered weights A = 1 − p and B = p at every p (asserted by the harness at 25 ms sampling over the full cycle; midpoint rendered A = 0.50, B = 0.50). `window.__state` exposes {p, domOpacityA, domOpacityB, renderedWeightA, renderedWeightB} as distinct fields.
ONE JS clock (progressAt, a single phase resolver): holdA (p=0) → dissolve (p = smoothstep over dissolveMs) → holdB (p=1) → loop-fade return (p reverses over loopFadeMs, same duration as the forward dissolve) → residual A hold; cycle exactly 14 000 ms (2400 + 250 + 3550 + 250 + 7550 residual, residual derived and asserted ≥ 0). At the seam p wraps 0→0. The file self-starts via its own requestAnimationFrame loop and reaches its scheduled wrap with no external caller.
Scene construction is dispatched by CONFIG kind keys through a builder registry: scene A builders "webpage" (search bar + hero card + result rows) and "panel" (title band + stacked-line panel); scene B builders "mark" (stacked-bars mark + wordmark) and "title" (centred wordmark + rule line). Every scene B builder runs on the layer's opaque full-stage field. Scene fixtures are generic: scene A is a simplified webpage (teal field, accent search bar with a descriptive training title, hero card, two result rows, scene label); scene B is a dark card carrying a stacked-bars mark (three horizontal bars of unequal lengths, colours drawn from the scene palette) above a generic studies wordmark, plus a scene label.
A validateConfig() function runs before any construction and records failures on window.__validationErrors: durations finite and ≥ 0, cycleMs finite and > 0, phase sum ≤ cycleMs, stage dimensions > 0, type sizes > 0, mark-bar array non-empty with finite positive members, counts integral ≥ 0, kind values known to the registry. On any failure, construction does not run.
Labels sit at distinct positions per scene: the scene A label sits below its result rows with clear space (row stack ends y=178, label y=182–198 inside the 203 px stage); the scene B label sits at y=150–166, so at the blend midpoint the two labels' rects do not intersect. Geometry and timing are all CONFIG-bound.
