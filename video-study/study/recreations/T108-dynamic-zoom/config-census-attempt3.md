## 2. Trusted defaults block (a priced surface, not a whitelist entry)
Validation reads every fallback from a single frozen DEFAULTS block that sits OUTSIDE the editable CONFIG surface; the validation code contains no numeric fallback literals of its own. Consumption sites: every validated field named in §1 reads its fallback from this block (group substitutions for whole malformed groups; per-field substitutions for invalid numerics; range resets for inconsistent timing sets, non-positive dimensions, and out-of-range fractions). Corruption probe: a size field corrupted to −999 inside the editable CONFIG is replaced by the block's value (9), proving the fallback does not read the corrupted object. The block duplicates the default values by design — that duplication is the mechanism that keeps corrupted configuration from supplying its own fallback.
