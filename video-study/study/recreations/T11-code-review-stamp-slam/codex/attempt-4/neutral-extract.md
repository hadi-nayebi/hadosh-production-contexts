# T11 — Code-review UI + stamp slam · neutral build facts (score-blind extract)

Permitted-fields schema for this extract: construction facts (what the file does, stated neutrally) + check names with pass/fail results only. No scores, no targets, no history.

## Construction facts
- One self-contained HTML file; all variables in a CONFIG object at the top of the script; URL overrides for titles/stamp/cardMs/accent/bg are parsed strictly (an unsigned-integer grammar for cardMs), applied to a candidate copy, deep-validated, and only then adopted — an invalid candidate is rejected atomically and recorded in an observable rejected list while the default configuration renders. Empty, duplicate, and excess override parameters are each rejected with a named error in the same observable record.
- Scheduling is a single absolute timeline computed from CONFIG: five cards with per-card durations [3000, 1000, 2000, 2000, 2000] ms across a 10000 ms loop, counter spans, and one stamp event per card whose data flag marks it merged. Displayed state is a pure function of loop phase; a frame that skips several checkpoints reconstructs exactly the state those checkpoints produce; pause stores the phase and resume shifts the time origin; loop rollover is phase modulo.
- Derived subordinate durations: each card's counter span is the configured counter duration capped by the card duration minus the whip duration. Each merged card's stamp offset is the smaller of a configured fraction of its card duration and the latest offset that lets slam + hold + hide complete before the next whip window opens; the hold is the remainder of that budget and the hide completes at the whip window's opening edge. At the default durations: first merged card stamp spans 1890–2850 ms (held at the 2500 ms phase); second merged card stamp spans 7260–7850 ms (slam completes at 7390 ms, held at the 7500 ms phase).
- Stamp rendering: scale and opacity come only from the phase function; the stamp element's CSS transition is pinned to none at setup and on every render.
- Approvals counter: three digit columns; the ones column rolls continuously with the rising value; each higher column holds its settled digit and eases to the next digit only across the final fraction of its own carry span, so at every counter completion each column's displayed strip position is exactly its settled digit. No blur is applied to the counter.
- Card transitions: one 300 ms envelope per swap, including across the loop boundary (the final card whips into the first card's entrance); swap at the envelope midpoint, horizontal travel 130 px, blur peaking at the midpoint, a horizontal streak scale plus a skew component, opacity 1 throughout.
- Checks panel: row states, status-pill text and tone, check-state symbols, and interface labels are data in CONFIG; while a merged card's stamp is displayed, the pill shows the merged entry. Check-state colors, pill tones, and palette colors are applied via CSS custom properties at init.
- Arch: code-drawn pointillist arch from a shape function exposed as a pure cell function; geometry constants (profile knee, half-width base/top, crown exponent, leg start/gap, band frequency/phase/threshold, dark-cell pattern multipliers and modulus) and the three glyph characters live in CONFIG; the leg opening spans 0.34 of the normalized half-width, the opening height fraction is 0.464 of the arch height, the crown peakedness measure (one minus the upper-region half-width ratio) is 0.228, and glyph size is 6.4 px on a 36×28 grid.
- Reviewer figures are DOM figures (head, arms, body, legs) built from CONFIG figure dimensions including stroke widths; counts per card are CONFIG data.
- Stamp placement (left/top percentages), border width, padding, background, and font stacks are CONFIG values applied at init. Type sizes are CONFIG values applied at init.
- Validation enumerates every container the render path dereferences and rejects — without throwing — when any is absent or a required member is missing; scalar ranges are checked for every numeric family (durations, digit base, whip scalars, stamp scalars and strings, arch fractions and pattern integers, type/stage/figure values); a rejected candidate leaves the default configuration and timeline completely unchanged.
