Reusability is strong for ordinary phrase, palette, and tempo changes, but the file does not yet support arbitrary language, phrase length, and duration reliably.

- **CONFIG coverage:** Content, palette, layout, and motion controls are substantially consumed. Duration precedence is explicit and usable through `CONFIG.durations`; editing the apparent top-level `formMs`/`holdMs`/`dissolveMs` values alone has no effect because resolution overwrites them. Palette endpoints accept six-digit hex only: shorthand hex and CSS color names silently produce incorrect colors. `fontWeight` is neither normalized nor URL-overridable, contrary to the record’s blanket numeric-validation claim.
- **Long phrases and tiny canvases:** The fit loop terminates safely, but reaching `fontFloorPx` merely reports `shortfall`; drawing still proceeds and can clip text. Sparse sampling can yield no targets for small glyphs. Multiline wrapping splits on whitespace, so languages without spaces receive no useful word wrapping. Diacritics depend on actual font coverage and glyph bounds, which the stub suite cannot establish.
- **Empty and single phrases:** One phrase loops correctly. Empty input restores the specimen phrases, avoiding a crash but unexpectedly displaying unrelated content. Production needs an explicit empty-content policy.
- **Extreme timing:** `holdMs: 10000` is supported. `formMs: 0` still consumes a frame and briefly draws an initial formation state. The scheduler advances only one phase per frame and discards elapsed overshoot, so zero and short durations do not faithfully reproduce configured timing. A three-second beat is configurable, but its actual duration depends on frame cadence.
- **Pool swaps:** Borrowed coverage grows with demand, but the pool and reserve never shrink. A large phrase followed by a small phrase retains the earlier background density under `drift-fade`; `capped-ambient` limits surplus drawing but leaves reserves uncapped. Capacity growth repeatedly scans the pool, making large target counts costly. The reported HELLO/WORLD swap demonstrates basic reassignment, not resilience to large density changes.
- **Determinism:** Seeded randomness and restart are meaningful strengths. Reproduction holds with the same viewport, font rasterization, and frame-step sequence. Config alone does not determine identical choreography: frame-dependent scheduling, per-frame trails, resizing, and numerical integration affect the result.
- **Additional robustness gap:** Removing or invalidating `presets.original` while selecting an invalid preset can leave duration resolution dereferencing an undefined preset.

The build record supports configuration consumption and controlled logic behavior. Its stubbed canvas does not establish multilingual readability or real-font fitting.
