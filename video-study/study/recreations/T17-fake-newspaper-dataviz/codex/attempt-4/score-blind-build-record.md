SCORE-BLIND BUILD RECORD (construction facts only)

The recreation is one self-contained HTML file. All visuals are generated procedurally as DOM and inline SVG from a single CONFIG object (content, palette, fonts, timing, layout, formatting, bounds, figure records); there are no external assets and no specimen media in the file. Six figure factories (line chart, waffle, stacked bars, org chart, counter graph, correction) each take a mount point, their figure data record, and an injected dependency set, and return a progress renderer. A deterministic layout model computes type sizes, spacing, geometry and fit at any stage width; a validation function collects named errors for out-of-boundary or malformed configuration, and the scene renders collected global errors in a warning element when any exist.

Construction properties of this build:
- Figure spacing (figure padding, heading margins, per-figure row gaps, source-line margin, bottom clearance) is held in single named layout values consumed by both the stylesheet/builders and the fit model; the modelled phone stage height is 553px at 360/390px widths against a 640px budget, and 619px at the maximum supported stack count, with the binding figure's bottom 8px above the stage bottom.
- Label-class text has a 12px floor at phone widths; source lines use a dedicated secondary palette colour at full opacity with a modelled contrast of 6.03:1 on the paper ground.
- The correction stamp is positioned from its rotated bounding-box (transformed bounds), and its entrance scale curve starts at the fitted cap for the layout and contracts through overshoot, compression and settle.
- The counter graph's cliff marker position derives from the same animation-progress-to-x mapping the graph trace is drawn from. The line chart's final data point produces a final-segment rise of 0.44 (the preceding fall is 0.60).
- The waffle summary's completed hold is derived from its length at 20ms per character (89 characters -> 1.780s fully visible), with typing occupying the remainder of the figure's window; a summary too long to type and hold inside its window is rejected by validation.
- The stack counter counts settled units, so its final count coincides with the last unit's settle moment. The org-chart badge has a timed entrance (progress-normalized duration 0.15, eased), beginning at 2.400s and completing at 2.850s inside its figure's window.
- Actual sub-animation completion times within their windows: line-chart draw 2.760s (hold 0.840s); summary typing 2.120s (hold 1.780s); stack settle 2.700s (hold 0.900s); badge entrance 2.850s (hold 0.750s); counter collapse 3.400s (hold 0.600s); final note 2.720s (hold 1.080s).
- All motion parameters (easing exponents, animation-fraction floor, entrance durations) and all formatting strings (counter locale, count wording, node symbol, badge separators) are named CONFIG values; figure windows are validated for contiguity and total coverage of the 22.5s duration; unsupported figure types produce a named validation error instead of mounting silently.
- The waffle grid is laid out in explicit rows at the same gap pitch the layout model budgets; org-chart row capacity is computed with the actual row gap.
- A mutation-based census over all 258 CONFIG leaves found every leaf consumed (0 unconsumed); a measured-fit table over the six figures at 360/390/960px found containment at every width.

Named limitation: the piece renders its first frame on load but does not start playback on its own; playback requires the Play control or an external clock driving its setTime/play interface.
