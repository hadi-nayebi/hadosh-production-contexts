SCORE-BLIND BUILD RECORD (construction facts only)

The recreation is one self-contained HTML file. All visuals are generated procedurally as DOM and inline SVG from a single CONFIG object (content, palette, fonts, timing, layout, formatting, bounds, figure records); there are no external assets and no specimen media in the file. Six figure factories (line chart, waffle, stacked bars, org chart, counter graph, correction) each take a mount point, their figure data record, and an injected dependency set, and return a progress renderer. A deterministic layout model computes type sizes, spacing, geometry and fit at any stage width; a validation function collects named errors for out-of-boundary or malformed configuration before layout or mounting, and the scene renders collected global errors in a warning element when any exist.

Construction properties of this build:
- Figure changes are staged transitions, not panel swaps: a 0.45s transition straddles each figure boundary — the outgoing figure fades and rises out over the first portion while displaying its completed state, and the incoming figure fades and settles in over the second portion, with a brief overlap where both are partially visible; at no sampled instant are both panels fully transparent, and the incoming figure's mechanism progress begins at its window boundary. The masthead is persistent and never participates.
- The stack's unit arrivals form a ladder whose first unit starts at exactly zero progress and whose last unit settles exactly at the animation-portion end, for any supported unit count (including a single unit); the displayed counter counts settled units, and the count equals the physically settled count immediately before and at every unit's settle threshold, at the default count and under swapped counts.
- The waffle summary is 68 characters. Typing runs at a dedicated rate of 30ms per character (2.04s, about 33 characters per second), completing 2.74s into its 4.5s window; the completed text then remains for 1.76s, above its length-derived reading floor of 1.36s (20ms per character). A summary too long to type and hold inside its window is rejected by validation with a named error.
- Figure windows: 3.3 + 4.5 + 3.6 + 3.6 + 3.7 + 3.8 = 22.5s total, validated contiguous with full coverage. Actual sub-animation completion times within their windows: line-chart draw 2.483s (hold 0.817s); summary typing 2.740s (hold 1.760s); stack settle 2.700s (hold 0.900s); badge entrance 2.850s (hold 0.750s); counter collapse 3.100s (hold 0.600s); final note 2.720s (hold 1.080s). Because transitions straddle boundaries, the fully opaque hold of a completed figure is its completed hold minus 0.225s (for example the summary's fully opaque hold is 1.535s).
- Text wrapping is computed on word boundaries with per-character-class width factors (narrow, wide, uppercase, digit, space), and the layout the model computes is the layout the renderer uses: figure titles, source lines and the waffle summary are rendered as exactly the line spans the word model produces at the stage width, so modelled line breaks are the displayed line breaks. Card text wraps inside the card's border-box inner width (declared width minus borders and padding, a single set of named layout values shared by the stylesheet, the builders and the fit model).
- The org-chart badge's entrance scale is fitted to its layout (the entrance starts at the smaller of the configured 1.6 and the ratio of content width to badge text width — 1.117 at 360px), and its transformed bounds are reserved in the figure's height accounting; the correction stamp keeps its positioned rotated-bounding-box construction. The counter card's subtext uses the stronger secondary palette colour modelled at 6.03:1 contrast on the paper ground.
- Shared component geometry (card padding, border and radius; dot border; stamp border, radius and padding; stack-unit border and radius), the stack unit symbol and the waffle's inactive-dot opacity are named CONFIG values consumed by the stylesheet (via custom properties), the builders and the fit model alike. Masthead height derives from the actual masthead string; source lines reserve their word-model line count; org node sizing includes the node symbol glyph.
- Validation requires the first figure to start at zero, positive-integer waffle and stack counts, a supported arrival-span/count relation, safe-integer counter values, non-empty node collections, and numeric (not string-typed) window values; absent configuration groups and absent collections route to named errors instead of throwing, and figures with validation errors are excluded from geometry computation and mounting.
- Playback starts automatically when the file is used standalone (top-level); when embedded, an external clock drives its render/setTime interface and no automatic start occurs. The public interface is window.T17 = {config, render, fitReport, validate, setTime, play, pause, restart, time, playing}.
- A mutation-based census over all 278 CONFIG leaves found every leaf consumed (0 unconsumed); a measured-fit table over the six figures at 360/390/960px found containment at every width with the binding figure's bottom 8px above the stage bottom (label-class modelled ink height 8.6px at the 12px type floor is filed in the fit table as an advisory hit list of 19 rows).

Named limitation: no rendered-pixel verification exists for this build (see the technique facts' verification limitations); geometry, transition and playback evidence is logic-level.
