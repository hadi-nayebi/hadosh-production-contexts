### Findings

- **State content and count are configurable.** In `recreation.html`, `stateAt` maps labels, population figures, `electors`, `tagged`, and `enterIdx` from `cfg.states`. The SVG renderer reads each state's silhouette points from the same array. The Wave 37 `SWAP-CONTENT` receipt shows Beta framed, Alpha unframed, counts of 7 and 9, and Beta’s population formatted as `120,000`. Entry order is independently supported by the `s.enterIdx * cfg.tileStaggerMs` calculation. The raw swap line does not print the resulting entry order. The layout centers one state and puts every state after the first in the same right-hand slot. If reuse needs more than two states, derive positions from the array or add explicit positions. Otherwise, validate the supported state count.
- **Timing parameters move playback and its probes.** The Wave 37 `SWAP-TIMING` receipt moves the square probe from 16,000 to 17,500 ms and `completeAtMs` from 16,500 to 18,000 ms, both by 1,500 ms. `SWAP-TIMING-TILES` moves both tile probes by 500 ms while reproducing their reported progress values. The two negative swaps show `validateConfig` rejecting phase-order violations, but the SVG entry point never calls it. Call it before playback so edited configurations get the same checks. Also clarify `tIconMs`: in `stateAt`, it shifts the exit schedule, while the icon and banner remain visible before that instant. If it is intended as an onset control, test a delayed start and gate visibility on it.
- **Scene color is configurable, with two evidence gaps in the census.** `SWAP-PALETTE` reports both the frame and enslaved numeral fills changing to `#2e9e6b`, consistent with their shared `P.frame` binding in the renderer. Counting the named entries in `CONFIG.palette` gives 15, including `tagText`; the A6 completion wording should make clear that `tagText` is included in that total. The corrected A13 census summary also mentions `states[].id`, which is absent from the supplied source. Reconcile those entries with the build.
- **Some literals are structural, while two retain the original subject.** SVG path proportions, baseline multipliers, and row-major index arithmetic define the current template. `fillOrder` accepts only `row-major` and never reaches rendering, so it is a format constraint rather than a selectable layout. The HTML `<title>` and SVG `aria-label` both hardcode the original technique name. Bind both to a CONFIG title so a content swap updates what the standalone page announces.
