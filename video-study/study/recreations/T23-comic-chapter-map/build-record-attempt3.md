## Construction (what changed in this attempt, stated neutrally)

One self-contained HTML file: a DOM grid page (cream comic page, header strip, numbered yellow-tabbed panels with code-drawn SVG miniatures) playing a looping sequence of appearances; each appearance fills more panels, holds, then the camera dives into the next chapter's panel, which takes over the frame. All variables live in one CONFIG object; URL parameters override them after strict validation. No specimen media, no traced assets, no captions/subtitles.

- **V-audit (validation termination + range audit).** Every numeric field of the nested groups (`layout`, `labels`, `typography`, `artViewBox`) now carries an explicit terminating range with default restoration on violation — including `labels.shrinkStepPx`, which must be strictly positive (range 0.05–5) because both shrink helpers loop on it. `labels.maxPx` is raised to at least the resolved `minPx` when the pair inverts. `labels.numberPadWidth` is range-checked as an integer; `separator` / `generatedTitlePrefix` must be non-empty strings. `layout.diveEasing` must be a CSS keyword or a well-formed `cubic-bezier(...)` (four numeric components, leading-dot decimals allowed). Palette colors accepted from overrides are stored trimmed.
- **G-clamp (relational geometry fallback).** After individual validation, a relational pass prices the combination at the fallback stage width (360 px): while the inner panel width would fall below 24 px or the inner height below 12 px, it clamps border, then gap, then column count — each clamp emits a named `geometry:` warning. The dive transform additionally floors its inner rectangle at 1 px per side, so no accepted configuration can produce non-positive inner dimensions.
- **R-config (renderer consumes resolved config).** The tab label text is built with `cfg.labels.separator`; the DOM refinement decrement is `cfg.labels.shrinkStepPx`; number-only extraction splits on the configured separator; the art renderer receives the fallback art kind from the resolved configuration at its call site.
- **S-schema (registry schema + fallback resolution).** Registry validation now checks primitive FIELDS, per kind: required numeric fields finite (rect/circle/line), grid fills a non-empty string array with positive cell size and integer cols/rows, graph nodes as numeric pairs with every edge index inside the node range and a positive node radius, circlesRow with a positive radius and integer count ≥ 1, text with a positive size and a string content or well-formed segments. An entry left with no valid primitives is removed. The registry is cleaned BEFORE panel art references resolve, the fallback kind is itself validated against the cleaned registry, and appearances restored from defaults (when every supplied entry is invalid) are re-validated against the CURRENT panel count. Null/malformed panel and appearance entries are dropped or replaced with named warnings instead of throwing.
- **O-routes (override surface).** New routes: `numbers=` (per-panel numbers), `artViewBox=WxH`, `fallbackArtKind=`, and `cfg:artViewBox.<field>=` nested overrides. Unknown query keys produce a named warning; an empty `appearances=` produces a named warning; a whitespace-only panel title slot produces a named warning.
- **F-floor (label fit floors + arrangement order).** Both modelled shrink loops and the DOM refinement clamp every decrement at the floor (`max(minPx, px − step)`), so a size can land exactly on 11 px but never below it. The DOM refinement's arrangement order is single → two-line → number-only: a single-line tab still overflowing at the floor is rebuilt from the two-line split (shrunk again within the floor) before the title is dropped. The number-only threshold for the longest default title is computed from its balanced longest line of 13 glyphs: 13 × 0.52 × 11 + 14 ≈ **88.4 px** of tab width at the 11 px floor.
- **H-header (header policy).** The header fit now prices a named reserve (`layout.headerReservePx`, 16 px) inside its available width, and returns a policy the DOM layer honors: shrink to the named 10 px floor (`floor`); if still too wide, shrink toward an absolute floor of 8 px (`reduced-floor`); only if still too wide may the header wrap (`wrap`, fits:false) — and the DOM layer then actually sets wrapping instead of hiding overflow.
- **C-camera (camera + schedule continuity).** The dive-entry identity snap now fires on FRESH entries only: on the resume path the frozen transform is passed through and the dive animates from it. After a dive's render, the due phase is re-derived — if the dive phase expired during rendering, the dive is rejected and the currently due phase is applied instead. The scheduler recomputes its next deadline AFTER the step's render, from the phase due at the post-render elapsed time. A resize during dive/hold recomputes the active dive transform against the resolved panel bounds at the new stage width.
- **Open design point (documented, not built):** the 150 ms hold + 250 ms dark pause remain preview-loop punctuation; the production handoff into the chapter scene is a production-design decision, not part of this recreation's construction.
