## Construction (what changed in this attempt, stated neutrally)

One self-contained HTML file: a DOM grid page (cream comic page, header strip, numbered yellow-tabbed panels with code-drawn SVG miniatures) playing a looping sequence of appearances; each appearance completes more panels, holds, then the camera dives into the next chapter's panel, which takes over the frame. All variables live in one CONFIG object; URL parameters override them after strict validation. No specimen media, no traced assets, no captions/subtitles.

- **Progress state model.** Panel state now carries completed membership and target membership as independent facts, plus their overlap (a target already inside the completed set) and a force-filled flag. A new CONFIG group `progress` selects the target policy: `mark` (default) — an upcoming target renders its miniature withheld (ghost number shown), carries an accent outline driven by `progress.targetOutlinePx` and a dedicated target tab colour (`palette.tabTarget`), and is never counted as completed; `fill` — the previous force-fill behaviour, explicitly chosen. The DOM exposes `dataset.completed` / `dataset.target` / `dataset.overlap` per panel and `dataset.state` per tab. Displayed completed counts are the configured 4→8→12 under both policies; under `mark` the illustrated totals equal the completed totals.
- **Measured tab refinement.** The DOM tab refinement's fallback decision is driven by measured rendered state: the tab's line count is counted from a Range over its rendered content (one client rect per rendered line box), horizontal containment from `scrollWidth` vs `clientWidth`, and tab height against the panel's inner height; the measured line count is recorded per tab (`dataset.lines`). The modelled label policy gained the matching vertical term: a two-line arrangement must also fit the panel's inner height (two lines at size × tab line-height + vertical padding + border), shrinking within the floor and falling to number-only at the floor. A forced three-line fixture (pre-line text with three explicit lines) exercises the measured path: line count 3 is a violation at every size, so the tab falls to number-only.
- **Header growth.** Header height is computed in one place: in wrap mode the header's own height grows to the wrapped content height (lines × size × `typography.headerWrapLineHeight`, a CONFIG value), and grid offset, panel positions, and stage height all derive from the grown height. The DOM sets the header element's height from that value; the previous post-hoc stage patch is removed.
- **Registry data route + extension boundary.** A `registry=<kind>:<prim>;<prim>…` override supplies a complete new art kind composed of supported primitives as JSON data, with no source edit; panels reference it by name. The boundary is printed in comparison.html: registry data is suppliable; a new primitive kind remains a code change (schema + renderer).
- **Minimum stage width.** `layout.minStagePx` (240) is declared in CONFIG, priced as its own regime by the relational geometry clamp, and enforced at runtime: below it, the layout is computed at the minimum width, the stage takes that explicit width (visible overflow), and a named warning is emitted. Feasibility at the minimum width is asserted under a hostile column/gap/border combination.
- **Silent paths closed.** A blank art slot in `panels=TITLE@ ` warns and leaves art unchanged; panel numbers over 8 characters truncate with a named warning; duplicate scalar query keys warn (first value wins, visibly); the known-keys map is null-prototype, so `toString`/`constructor` warn as unknown keys like any other.
- **Registry schema depth.** Optional primitive fields are validated: stroke widths (finite, >0, ≤40), opacity (0–1), paints (hex colour, palette token, or `none`), text weight (keyword/100–900 grammar) and size (≤200), and transforms against a stated grammar — a whitespace-separated sequence of `rotate(a [x y])` / `translate(x [,] y)` / `scale(sx [,] sy)` calls with finite numeric arguments, each |value| ≤ 10000, the calls covering the entire string. Resource ceilings live in a CONFIG `ceilings` group (max grid cells 96, max circlesRow count 24, max graph nodes 24, max graph edges 64), each with an over-ceiling drop case. An entirely rejected registry restores the default registry (deep copy) with a named warning instead of leaving blank art.
- **Literals moved into CONFIG.** Header wrap line-height, warning-strip padding and z-index, the SVG `preserveAspectRatio`, primitive default stroke width and text weight, the geometry inner-dimension thresholds, and the gap clamp step are CONFIG keys, each consumed by the renderer/geometry (consumption census below). One previously bound key, `layout.tabOverflowAllowancePx`, was consumed by no effect after the measured refinement replaced its role; it is removed from CONFIG and its validation line (interface change, printed here).
- **Time-derived camera.** The CSS-transition camera is replaced by a pure function of dive progress: `p = clamp(inPhaseMs / diveMs)`; the configured easing maps p to an interpolation fraction (keyword mappings plus a cubic-bezier solver); the transform interpolates identity → dive endpoint. A requestAnimationFrame loop evaluates the camera from elapsed phase time. Entry at any point of the dive phase — fresh, late, or resumed — evaluates the same function at the current progress; resize re-evaluates at the same progress against the recomputed endpoint; hold pins p = 1. The frozen-transform capture and the identity-snap branch are gone.
- **Open design point (documented, not built):** the 150 ms hold + 250 ms dark pause remain preview-loop punctuation; the production handoff into the chapter scene is a production-design decision, not part of this recreation's construction.
