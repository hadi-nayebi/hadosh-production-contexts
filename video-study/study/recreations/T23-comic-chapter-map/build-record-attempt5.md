## Construction (what the file now does, stated neutrally)

One self-contained HTML file: a DOM grid page (cream comic page, header strip, numbered yellow-tabbed panels with code-drawn SVG miniatures) playing a looping sequence of appearances; each appearance completes more panels, holds, then the camera dives into the next chapter's panel, which takes over the frame. All variables live in one CONFIG object; URL parameters override them after strict validation. No specimen media, no traced assets, no captions/subtitles.

- **Progress surface.** Panel state carries completed membership and target membership as independent facts, plus their overlap. A dive target ALWAYS renders its miniature — the camera dives into the chapter's scene in every appearance. The CONFIG `progress` group selects the target's styling: `mark` (default) — an upcoming target renders its miniature WITH a distinct mark (accent outline driven by `progress.targetOutlinePx`, dedicated target tab colour) and is never counted as completed (displayed completed counts are the configured 4→8→12; illustrated totals are 5→9→12); `fill` — the target renders in completed style. The DOM exposes `dataset.completed` / `dataset.target` / `dataset.overlap` per panel.
- **Camera.** The transform is a pure function of dive progress evaluated from ONE shared elapsed accessor: while paused, the elapsed time is the frozen elapsed, so a resize during pause re-evaluates the camera at the frozen progress against the recomputed endpoint (progress preserved, no advance, no snap). A zero-duration dive is complete at every point of its phase, so the hold state displays the endpoint transform itself. Easing is handled by ONE shared parse consumed by both validation and the camera: keyword easings map to their true CSS cubic-bezier coordinates (ease .25,.1,.25,1 · ease-in .42,0,1,1 · ease-out 0,0,.58,1 · ease-in-out .42,0,.58,1 · linear 0,0,1,1), and any string that validates evaluates as itself.
- **Registry rendering safety + consistency.** Every attribute value the SVG renderer emits passes through an attribute escaper. Validation covers the previously unvalidated consumed fields: rectangle corner radius (numeric, ≥0), text anchor (start/middle/end), polygon points (a numeric coordinate list), and palette-token membership (a token naming no palette entry fails validation instead of reaching the SVG unresolved). One shared attribute treatment renders the accepted optional fields (stroke, stroke-width, opacity, transform) for every primitive kind; grouped primitives (grid / graph / circles-row) carry them on a group wrapper.
- **Override transport.** Duplicate nested (`cfg:`) keys are named with a warning and the first value wins — the same contract as scalar keys. String override values are whitespace-normalized before landing, and enum validation normalizes before checking, so a padded value lands instead of resetting. The registry data route transports its primitives as ONE JSON structure (`registry=<kind>:[<prim>,…]`): characters inside JSON strings are data, never separators; malformed JSON warns and is ignored. A new primitive kind remains a code change (schema + renderer); that boundary is printed in comparison.html.
- **Relational geometry rejection.** The geometry clamp is followed by a final feasibility check across every priced regime: if the clamped combination still cannot meet the declared inner-dimension contract, the combination is rejected — geometry fields and inner thresholds restore to their defaults together, with a named warning — so an accepted configuration is coherent under its own contract. Feasible-after-clamp combinations are not rejected.
- **Tab occlusion budget.** A CONFIG key (`labels.maxTabHeightFraction`, 0.65) budgets each tab's height against its panel's inner height, consumed by BOTH the modelled label policy's vertical term and the DOM refinement's violation test: a two-line tab shrinks within the floor to fit the budget, and at the floor falls to number-only rather than breaching it. At 360px the longest title's tab measures 35.8px against a 60.8px panel interior (fraction 0.588), leaving the miniature's lower ~41% plus its sides unobstructed; across all panels at 360px the largest tab fraction is 0.629.
- **Policy limits as configuration.** A CONFIG `limits` group (maximum panels, maximum columns, header/title/number character caps, clamp iteration cap, border clamp step) is validated before use and consumed at every site that previously embedded those values. The header's minimum font floor is 11px, so the fitted header meets the phone legibility floor at 360px (fitted at 11.0px, width margin 38.3px).
- **Open design point (documented, not built):** the 150 ms hold + 250 ms dark pause remain preview-loop punctuation; the production handoff into the chapter scene is a production-design decision, not part of this recreation's construction.
