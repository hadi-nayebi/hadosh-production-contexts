- Validation: a feasibility rejection restores the full joint geometry state (columns, gaps, borders, aspect, breakpoint) and re-checks it; a still-infeasible restore falls back to the full geometry group defaults and is re-checked again; a named rejection warning remains if even that fails.
- Overrides: nested group overrides land before scalar routes resolve, so panel counts, generated numbers, and generated titles all price against post-override limits, padding, and prefix.
- Art renderer: grouped primitives forward their accepted stroke and stroke width on the group wrapper; a missing fill on any primitive kind resolves through a configured default fill entry (palette-resolved, membership-checked at validation) — the renderer cannot emit an undefined fill.
- Easing: the single shared parse rejects any non-finite coordinate; invalid easings restore the default with a named warning.
- String handling is per field class — TOKEN fields (enums, art kinds, easing names, palette tokens, colours) are trimmed before validation; FREE-TEXT fields (label separator, generated-title prefix, header text, panel titles) are preserved verbatim, with type and length checked only.
- Header: the size estimator includes the configured letter-spacing term; a measured refinement pass in the DOM layer is authoritative (shrinks by measured overflow toward an 11 px floor that no path goes below, then wraps with grown height, and the stage height grows with it).
- Panels: each panel is a two-row layout — the tab occupies a dedicated band whose height is the label policy's result (capped by the configured band-share fraction of the panel interior), and the miniature's art region is the remaining rectangle. The dive transform is derived from the art-region rectangle, and coverage of the viewport by the art region is asserted for every panel at 360 and 960 px.
