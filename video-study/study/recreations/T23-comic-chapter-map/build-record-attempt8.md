## What the build is
A parameterized recreation of a comic chapter-map motif: a cream page of numbered, yellow-tabbed panels under a header strip; three appearances fill more panels (completed 4 → 8 → 12; the dive target also renders its miniature, so illustrated totals read 5 → 9 → 12); the camera dives into the appearance's target panel until its miniature covers the viewport. All variables live in one CONFIG; URL overrides resolve after strict validation with named warnings.

## Construction notes (this attempt)
- Presented endpoint, claim-scheduled: when the tracked dive step's boundary is crossed, its endpoint transform is committed as a presented state before any reset can consume it, for BOTH callback orders — the claim itself (timer-first or camera-first) schedules the deferred reset one frame boundary later, so a camera-first claim never depends on the timer callback. While a presentation is pending, the scheduler's post-render reconciliation may not apply a step: the pending presentation wins, the step is logged as deferred, and the deferred apply applies the then-current phase. The presented interval is at least one frame boundary before any reset: at the defaults (hold/pause 0) it is exactly one frame boundary, charged against the immediately following dwell; with a nonzero hold configured, the endpoint additionally remains presented through the hold — no blanket exactly-one-frame claim is made for that configuration. Deadlines stay anchored to the absolute schedule (cycle origin + nominal offsets, 2,190 ms), so no drift accumulates. Late entry necessarily leaves less displayed time before an unchanged deadline — scheduling is absolute and phases are never compressed against a moved deadline; wholly-elapsed steps are logged as skipped (a skipped dive's endpoint is logged NOT PRESENTED), never queued or replayed. Painted-frame presentation is NOT VERIFIED (see Limitations).
- Magnitude/finite validation: every numeric configuration field is validated in its own domain — discrete fields require safe integers, continuous fields require finite bounded numbers — and a non-finite or unsafe-magnitude input (a 400-digit-class literal per field) resolves to the field DEFAULT with a warning that names the field; the warning text and the installed value are asserted together, so a warning never claims a discard that did not happen. The sweep is enumerated from CONFIG itself (67 numeric leaves) plus the array/count surfaces (appearances, panel count); after any such input the whole resolved configuration is finite and the timeline total is finite. Valid non-default values, including fractions on continuous fields, still land and take effect.
- Path-data grammar: registry `path` primitives validate their `d` against the SVG path grammar at validation time (command arity, arc flags as single 0/1 tokens, full-string token coverage). Malformed data drops the primitive with a named warning and the panel's art resolves through the fallback kind — invalid path data is never emitted.
- Structured panels route: a `panelsJson=` route carries a JSON array of title strings or {title, art, n} objects as ONE JSON structure, so arbitrary title free text (`|`, `@`, whitespace, case) lands verbatim. The legacy `panels=` route keeps working; its reserved-character contract (`|` separates entries, `@` separates title from art) is printed in comparison.html as documented surface.
- Line-count capability honesty: the implemented layout construction is the two-line split, so the exposed `labels.maxLines` surface is 1–2; values 3–4 are rejected by name with the implemented capability stated, rather than accepted and silently delegated to the two-line construction. (Restriction branch: no render route exists in this environment — see Limitations — so no N-line construction is claimed unrendered.)
- Restart: restart clears ALL presentation state — claimed endpoint keys, any pending deferred apply, the last-presented record, any held completion, and the absolute step bookkeeping — so a restarted cycle re-commits every appearance's endpoint exactly as a fresh start does.
- Skip-log completeness: every phase advance that skips display records through the same skipped log — the timer path, the deferred-apply path, the post-render reconciliation, and the dive-expiry re-derivation inside step application.
- Resize precedence: a resize renders FIRST, then evaluates against the post-render resolved geometry; a pending (or held) endpoint presentation takes precedence over ordinary dive evaluation and is re-committed from the new resolved record — no transform is computed against stale pre-render geometry and no partial-progress dive transform replaces a pending endpoint.
- Completion/handoff boundary: the final appearance's presented endpoint is the sequence's completion point, exposed as configuration-visible state — `handoff.holdOnComplete` (default off). With the boundary engaged, the deferred cut is held at the arrived scene (state readable via the `__t23Handoff` surface, completion notified through its callback registration) until the consuming sequence releases it (the `releaseHandoff` message command or `__t23Handoff.release()`); on release the absolute schedule resumes at the held dive's end. No scene content is built at the boundary; the boundary is the surface a consuming sequence holds against.
- Residual literals: the renderer's last-resort paint fallbacks resolve through the configured art defaults (no colour literal stands anywhere outside CONFIG), and the header measured-refinement loop's iteration ceiling is a named limits leaf consumed at its site.
- Retained machinery (unchanged in substance): validation-before-generation pass order; the complete paint-default contract (missing fill/stroke on any primitive kind resolves through the configured defaults; explicit `none` honoured as data); the emptied scheduler-floor control stays removed; shared resolved geometry (the camera endpoint derives from the rendered layout's resolved record); the tab estimator's letter-spacing term; casing/whitespace as configuration; the joint-geometry feasibility restore/re-check.
