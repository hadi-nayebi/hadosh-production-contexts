### Construction choice
DOM/SVG arc board in ONE self-contained HTML file: a pure layout core (computeLayout / stateAt / checkpointsOk — no DOM, node-testable) + a DOM render layer. Ballots are generated paper divs (tab strip in the column color + two ink lines) seated on 4 concentric arc rows; columns are arc SECTORS (ballots ranked by angle from the arc's start side, column counts handed out in that order — the specimen's geography, cured in Execute, see log); brackets are SVG arc paths + value chips clamped on-stage; the threshold is a gold radial line at the derived threshold angle; the sweep hand is an SVG needle from the board center easing to the target column's mean angle; the ballot box is a DOM box at the center. Legend + counts lines are generated from CONFIG brackets/columns (technique annotations, not captions).
Rejected: canvas particle field (wrong mechanic — discrete units; A5 flow-field inapplicable) · traced board image (purity refusal).
Phase machine (plan-review cure 2b): assemble → fill → brackets → sweep → hold, every transition derived from predecessor completion (bracketAt from fillEnd, sweepAt from bracketsEnd); completed artwork persists, only the current phase animates. Completion invariant (cure 1): computeLayout generates exactly `units` ballots, each with a column + a fill step; checkpointsOk() verifies count, sum, ordering, and sweep-within-duration.
Fidelity plan — implemented: board + box; ACT 1 (measured segment): entrance camera move with the board arriving assembled + tabbed, threshold line, brackets 10/28 on arrival, 9-bracket at ~6 s, annotation card at 9 s/10 s, hold; ACT 2 (lifecycle, separately timed): sector fill by column with tabs landing at each count step, all four brackets, sweep hand easing to the evidenced undecided-zone direction, hold; legend/counts annotations throughout.
