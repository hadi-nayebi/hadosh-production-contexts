- CONFIG keys: `states` [{id,cx,cy,r,ax?,ay?}] abstract blobs in a 360×260 viewBox (generated anchors, NOT traced boundaries) · `chips` [{name,label,stateId,elect}] (55 specimen entries, invented roster names — chips are generated initials-discs, never portrait photos) · `palette` {ground, land "#33523f", landAlt[5], chip, chipRing, chipInk, electBg, elect, label, labelText} · `placeMs` 240 · `holdAfterPlaceMs` 800 · `fullAtMs` DERIVED = chips.length × placeMs + holdAfterPlaceMs (= 14,000 at specimen values; never a stored literal) · `zooms` [{stateIds, atMs, scale}] authored against `authoredSpanMs` 14000, effective time rescales with the derived span · `chipR` 13 · `chipOffsets` deterministic same-state offsets · type sizes (initials 9, label 8.5, elect 7) · `fullLabel` "{n} ON THE MAP".
- Construction: one self-contained HTML file; inline SVG — ground rect + one circle per state blob inside a single camera group; chips as SVG groups (disc + initials + optional Elect tag + name plate) generated from CONFIG; camera = viewBox window computed from the active zoom's state centroid (one transform owns the stage; at fullAtMs the identity view owns it). Rejected: traced state-boundary map (purity refusal + the technique is placement, not cartography) · photographic portraits (purity refusal) · canvas (SVG/DOM text gives measurable label geometry).
- Label policy (codex-plan-review cure, applied): a chip's name plate shows only for (a) the most recently placed chip and (b) placed chips whose state is in the active zoom — never all 55 at once; discs + initials carry the full roster. Elect tags show on every placed elect chip.
- Camera/timing policy (codex-plan-review cure, applied): zoom atMs are authored against authoredSpanMs and rescale by fullAtMs/authoredSpanMs, so a compressed swap schedule keeps every zoom inside the run; checkpointsOk() rejects any config whose effective zoom time ≥ fullAtMs, whose zooms are unordered, or whose chips reference a missing stateId. Zoom order follows placement order (West 3000 → Central 7000 → East 11000) so each zoom's region is populated when the camera arrives (a defect found in self-verify v1 — zooms firing on empty regions — cured by this ordering).
- Failure points priced: 55-chip density (readability — measured below) · cardinality hardcoding (reusability — swap appends a 56th chip) · map-tracing temptation (purity — abstract blobs by construction).
- Plateau: FIRST-ATTEMPT; no prior average; expected stuck lens readability (chip density; family precedent T17's 28).
