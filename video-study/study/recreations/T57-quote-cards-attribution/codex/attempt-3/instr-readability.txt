## Construction
- One mounted DOM card (panel, glyph, quote-line divs, attribution line with speaker + occasion spans) inside a scene layer inside the stage, driven entirely by a CONFIG block: quote list (text, speaker, occasion, per-quote entrance start/duration, exit start/duration, optional per-quote anchor), palette, entrance mode, lifecycle mode, default entrance/exit spans, exit scale end value, hold duration, contrast floors and fallback policy, layout (stage size and aspect, anchor fractions, card width, padding, rule, height budget, shadow geometry), and type settings (sizes, weights, quote/glyph/attribution line heights, gaps, fit guard, size floors).
- Opacity ownership: in unit mode the card element alone carries the entrance/exit opacity and its children render at full opacity inside it, so every part of the card displays at the same effective opacity. In the staggered variant the parent carries the exit fade only and each child carries its own entrance progress, so no progress value is applied twice to the same content.
- Exit transform: one exit progress drives the scene layer's scale from 1 toward the configured end value (0.92 in the default configuration); the card is a child of the scene layer, so the same transform carries the card while the parent opacity fades it. The scene layer's scale returns to 1 for the second card.
- Anchors: a card's anchor fractions position the card's CENTER (left/top set from the fractions; the transform translates by half the card's own size). The global default is centered (0.5, 0.5). The second card's configured anchor is (0.37, 0.66) — the lowest-left center that keeps the full card inside the stage at the default card size (card width fraction 0.72 puts the left-edge limit at a center fraction of ≈0.36; the modelled card height caps the vertical center at ≈0.66). Transformed bounds were modelled at entrance (entrance scale 0.96 contracts about the center), hold, and exit (scene scale ≤ 1 contracts toward the stage center) for both cards: all inside the stage (model level).
- Timeline: every quote is wrapped and every start time is computed into a fixed table before playback begins; the render function is a pure function of time over that table, so a direct seek and sequential playback select the same card with the same opacities. In sequence mode, starts accumulate from spans; a staggered span runs from the entrance interval through the line reveals to the attribution's completion, plus the hold.
- Schedule validation, reported in the diagnostics object (`window.__T57.diagnostics()`): scheduled entrances must be in chronological order — an out-of-order schedule is rejected, reported in `validationErrors`, and the previous timeline is left unchanged; overlapping entries and exits that begin before their entrance completes are flagged in `overlapWarnings`; when the quote font reaches its floor and the complete card still exceeds the height budget, the excess is recorded in `fitOverflow`/`fitOverflowMaxPx`; a color that still falls short of its contrast floor after the fallback's step cap is recorded in `contrastFailures`; a color value that is not a six-digit hex string is recorded in `invalidColors`. A shorter configured duration extends to the derived requirement, recorded as `extendedDurationMs`.
- Text formation: greedy word wrap against canvas-measured text at the configured font; available width is the card width minus actual padding minus the rule. The attribution block is measured by a wrap simulation over the same available width: the attribution string is split on whitespace runs (each run collapses to one space, as the rendered inline spans do), every token is measured in its own role font (speaker weight; occasion italic at its weight), the speaker–occasion gap (configured, in em) is counted once and only when the occasion's first token lands on the same line as preceding content, a token wider than the available width is hard-split at character level, and the resulting line count is unbounded. The attribution renders with its own configured line height, and the vertical fit prices the attribution as simulated lines × attribution size × that line height. Vertical fit prices the complete card — padding, glyph (at its configured line height), gaps, quote lines, attribution — and shrinks the quote font toward its floor until the whole card fits the configured height budget. Measurements rebuild on resize and when fonts finish loading.
- Contrast: text colors (quote ink, speaker ink, occasion) must clear a 4.5:1 floor against the panel and the accent a 2:1 floor; under the configured "lighten" fallback policy a shortfall color is lightened toward white in fixed steps until it clears, and the adjusted value is what renders. /* Measured line formation: greedy word wrap against canvas-measured text at the
   configured font; available width = card width minus actual padding minus rule.
   No preset line breaks, no character-count splitting. Long unbroken tokens are
   hard-split only when a single token exceeds the available width. */
const measCtx = document.createElement("canvas").getContext("2d");
function measure(text, px, weight, italic) {
  measCtx.font = (italic ? "italic " : "") + weight + " " + px + "px " + CONFIG.fontFamily;
  return measCtx.measureText(text).width;
}
/* Attribution wrap simulation (model level). Token handling, stated explicitly:
   the attribution string is split on whitespace runs (each run collapses to one
   space, matching how the rendered inline spans collapse whitespace); every
   token is measured with its own role font (speaker tokens at the speaker
   weight, occasion tokens italic at the occasion weight); the gap between the
   speaker and occasion parts is the configured occasion gap, counted once and
   only when the occasion's first token lands on the same line as preceding
   content; a token wider than the available width is hard-split at character
   level across lines. The returned line count is unbounded. */
function chipWrap(q, availPx, chipPx) {
  const tokens = [];
  ("\u2014 " + (q.speaker || "")).split(/\s+/).filter(Boolean)
    .forEach(t => tokens.push({ text: t, weight: CONFIG.type.chipWeight, italic: false, part: "speaker" }));
  (q.occasion || "").split(/\s+/).filter(Boolean)
    .forEach((t, i) => tokens.push({ text: t, weight: CONFIG.type.occasionWeight, italic: true, part: "occasion", first: i === 0 }));
  if (!tokens.length) return { lines: 0 };
  const spaceW = measure(" ", chipPx, CONFIG.type.chipWeight, false);
  const gapW = chipPx * CONFIG.type.occasionGapEm;
  let lines = 1, curW = 0;
  for (const tok of tokens) {
    let rest = tok.text, firstChunk = true;
    while (rest.length) {
      const w = measure(rest, chipPx, tok.weight, tok.italic);
      const lead = curW > 0 ? (firstChunk && tok.first ? gapW : spaceW) : 0;
      if (curW > 0 && curW + lead + w > availPx) { lines++; curW = 0; continue; }
      if (curW + lead + w <= availPx) { curW += lead + w; rest = ""; }
      else {
        const room = availPx - curW - lead;
        let n = rest.length;
        while (n > 1 && measure(rest.slice(0, n), chipPx, tok.weight, tok.italic) > room) n--;
        if (n < 1) n = 1;
        curW += lead + measure(rest.slice(0, n), chipPx, tok.weight, tok.italic);
        rest = rest.slice(n); firstChunk = false;
        if (rest.length) { lines++; curW = 0; }
      }
    }
  }
  return { lines };
}
function wrapQuote(q, availPx, fontPx, chipPx) {

      if (measure(w, px, CONFIG.type.quoteWeight, false) > guard) {
        if (cur) { lines.push(cur); cur = ""; }
        let rest = w;
        while (measure(rest, px, CONFIG.type.quoteWeight, false) > guard && rest.length > 1) {
          let n = rest.length;
          while (n > 1 && measure(rest.slice(0, n), px, CONFIG.type.quoteWeight, false) > guard) n--;
          lines.push(rest.slice(0, n)); rest = rest.slice(n);
        }
        cur = rest; continue;
      }
      const trial = cur ? cur + " " + w : w;
      if (measure(trial, px, CONFIG.type.quoteWeight, false) <= guard) cur = trial;
      else { lines.push(cur); cur = w; }
    }
    if (cur) lines.push(cur);
    return lines;
  }
  /* Complete-card vertical fit: padding, glyph, gaps, quote lines and the
     attribution block (at its simulated wrapped line count and its own
     configured line height) are all priced; the quote font shrinks toward
     its floor until the whole card fits the height budget. Any remaining
     excess at the floor is returned as a reported overflow amount. */
  const W = stageW();
  const stageH = W * CONFIG.layout.stageAspectH / CONFIG.layout.stageAspectW;
  const chipLines = chipWrap(q, availPx, chipPx).lines;
  const fixedH = 2 * (W * CONFIG.layout.cardPadYFrac)
    + (W * CONFIG.type.glyphFrac) * CONFIG.type.glyphLineHeight
    + W * CONFIG.type.quoteGapFrac + W * CONFIG.type.chipGapFrac;
  function totalH(px, lines) {
    return fixedH + lines.length * px * CONFIG.type.lineHeight
      + chipLines * chipPx * CONFIG.type.chipLineHeight;
  }
  let lines = build(size);
  while (size > CONFIG.type.minQuotePx && totalH(size, lines) > stageH * CONFIG.layout.cardMaxHeightFrac) {
    size -= 1; lines = build(size);
  }
  const h = totalH(size, lines);
  const overflowPx = Math.max(0, h - stageH * CONFIG.layout.cardMaxHeightFrac);
  return { lines, fontPx: size, cardHeightPx: h, stageHPx: stageH,
           chipLines, overflowPx };
}

/* Contrast handling: text colors must clear the text floor against the card;
   the accent must clear the accent floor. When a color falls short and the
   configured fallback policy is "lighten", the color is lightened toward
   white in fixed steps until it clears (deterministic; the adjusted value is
   what renders). With any other policy value the colors render as configured.
   A color that still falls short after the step cap, and any color value that
   is not a six-digit hex string, is recorded in the diagnostics object. */
let diagnostics = { extendedDurationMs: 0, requiredMs: 0, quoteCount: 0,
  scheduleValid: true, validationErrors: [], overlapWarnings: [],
  fitOverflow: [], fitOverflowMaxPx: 0, contrastFailures: [], invalidColors: [] };
function isHex6(s) { return typeof s === "string" && /^#[0-9a-fA-F]{6}$/.test(s); }
function lum(hex) {
  if (!isHex6(hex)) return 0;
  const c = hex.replace("#", "");
  const v = [0, 2, 4].map(i => parseInt(c.substr(i, 2), 16) / 255)
    .map(s => s <= 0.03928 ? s / 12.92 : Math.pow((s + 0.055) / 1.055, 2.4));
  return 0.2126 * v[0] + 0.7152 * v[1] + 0.0722 * v[2];
}
function contrast(a, b) {
  const la = lum(a), lb = lum(b);
  return (Math.max(la, lb) + 0.05) / (Math.min(la, lb) + 0.05);
}
function lighten(hex, step) {
  const c = hex.replace("#", "");
  const ch = [0, 2, 4].map(i => parseInt(c.substr(i, 2), 16));
  const out = ch.map(v => Math.round(v + (255 - v) * step));
  return "#" + out.map(v => v.toString(16).padStart(2, "0")).join("");
}
function guardPalette() {
  const p = CONFIG.palette;
  for (const key of Object.keys(p)) {
    if (!isHex6(p[key])) diagnostics.invalidColors.push({ key, value: String(p[key]) });
  }
  if (!isHex6(p.card)) return;
  const fix = (key, floor) => {
    if (!isHex6(p[key])) return;
    let guard = 0;
    if (CONFIG.contrastFallback === "lighten") {
      while (contrast(p[key], p.card) < floor && guard < 20) { p[key] = lighten(p[key], 0.12); guard++; }
    }
    if (contrast(p[key], p.card) < floor) {
      diagnostics.contrastFailures.push({ key, ratio: Math.round(contrast(p[key], p.card) * 100) / 100, floor });
    }
  };
  fix("ink", CONFIG.contrastTextMin);
  fix("chipInk", CONFIG.contrastTextMin);
  fix("occasion", CONFIG.contrastTextMin);
  fix("chip", CONFIG.contrastAccentMin);
}

/* Precomputed timeline: every quote is wrapped and every start time is fixed
   before playback begins, so any seek lands on the same state sequential
   playback would show. In the scheduled lifecycle each quote carries its own
   entrance interval and exit interval; otherwise starts accumulate from
   entrance + hold spans, where a staggered span runs to the attribution's
   completion. The schedule is validated before it is adopted: out-of-order
   scheduled entrances are rejected and reported (the previous timeline is
   left unchanged); overlaps and exits that begin before an entrance completes
   are flagged in the diagnostics. The required duration is derived from the
   table; a shorter configured duration extends to the requirement and the
   extension is recorded in the diagnostics. */
let timeline = [];
function spanFor(entry) {
  if (CONFIG.entranceMode === "staggered") {
    return entry.enterDurMs + entry.wrapped.lines.length * CONFIG.lineMs
      + CONFIG.chipFadeMs + CONFIG.holdMs;
  }
  return entry.enterDurMs + CONFIG.holdMs;
}
function computeTimeline() {
  const W = stageW();
  const cardW = W * CONFIG.layout.cardWidthFrac;
  const avail = cardW - 2 * (W * CONFIG.layout.cardPadXFrac) - CONFIG.layout.rulePx;
  const fontPx = Math.max(CONFIG.type.minQuotePx, W * CONFIG.type.quoteFrac);
  const chipPx = Math.max(CONFIG.type.chipMinPx, W * CONFIG.type.chipFrac);
  const candidate = [];
  let cursor = 0;
  CONFIG.quotes.forEach((q, i) => {
    const w = wrapQuote(q, avail, fontPx, chipPx);
    const enterDur = typeof q.enterDurMs === "number" ? q.enterDurMs : CONFIG.cardEnterMs;
    const exitDur = typeof q.exitDurMs === "number" ? q.exitDurMs : CONFIG.exitDurMs;
    let start;
    if (CONFIG.lifecycleMode === "specimen" && typeof q.enterAtMs === "number") start = q.enterAtMs;
    else if (i === 0) start = 0;
    else start = cursor;
    const exitStart = (CONFIG.lifecycleMode === "specimen" && typeof q.exitStartMs === "number")
      ? q.exitStartMs : null;
    const probe = { quote: q, wrapped: w, startMs: start, enterDurMs: enterDur,
                    exitStartMs: exitStart, exitDurMs: exitDur, endMs: 0 };
    probe.endMs = exitStart !== null ? exitStart + exitDur
      : (CONFIG.lifecycleMode === "specimen" && typeof q.enterAtMs === "number")
        ? Math.max(start + enterDur, CONFIG.durationMs)
        : start + spanFor(probe);
    candidate.push(probe);
    cursor = Math.max(cursor, probe.endMs);
  });
  const errors = [], warnings = [];
  if (CONFIG.lifecycleMode === "specimen") {
    candidate.forEach((e, i) => {
      if (i > 0 && e.startMs < candidate[i - 1].startMs) errors.push({ type: "schedule-order", index: i });
      if (i > 0 && e.startMs < candidate[i - 1].endMs) warnings.push({ type: "overlap", index: i });
      if (e.exitStartMs !== null && e.exitStartMs < e.startMs + e.enterDurMs) {
        warnings.push({ type: "exit-before-entrance-complete", index: i });
      }
    });
  }
  diagnostics.validationErrors = errors;
  diagnostics.overlapWarnings = warnings;
  diagnostics.scheduleValid = errors.length === 0;
  if (errors.length) return; /* rejected: the previous timeline stands unchanged */
  timeline = candidate;
  diagnostics.quoteCount = timeline.length;
  diagnostics.requiredMs = timeline.length ? Math.max.apply(null, timeline.map(e => e.endMs)) : 0;
  diagnostics.extendedDurationMs = Math.max(0, diagnostics.requiredMs - CONFIG.durationMs);
  diagnostics.fitOverflow = timeline.filter(e => e.wrapped.overflowPx > 0)
    .map(e => ({ index: timeline.indexOf(e), overflowPx: Math.round(e.wrapped.overflowPx * 100) / 100 }));
  diagnostics.fitOverflowMaxPx = diagnostics.fitOverflow.length
    ? Math.max.apply(null, diagnostics.fitOverflow.map(f => f.overflowPx)) : 0;
}
function effectiveDuration() { return Math.max(CONFIG.durationMs, diagnostics.requiredMs); }

let lineDivs = [];

function buildQuote(i) {

  const q = entry.quote;
  cardEl.style.left = ((typeof q.anchorXFrac === "number" ? q.anchorXFrac : CONFIG.layout.cardAnchorXFrac) * 100) + "%";
  cardEl.style.top = ((typeof q.anchorYFrac === "number" ? q.anchorYFrac : CONFIG.layout.cardAnchorYFrac) * 100) + "%";
  quoteEl.innerHTML = "";

    quoteEl.appendChild(d); return d;

}
function clamp01(v) { return Math.min(1, Math.max(0, v)); }
function renderAt(tMs) {
  if (!timeline.length) { cardEl.style.opacity = 0; return; }
  let i = 0;
  for (let k = 0; k < timeline.length; k++) if (tMs >= timeline[k].startMs) i = k;
  if (tMs < timeline[0].startMs) i = 0;
  if (i !== curQuote) { curQuote = i; buildQuote(i); }
  const entry = timeline[i];
  const local = tMs - entry.startMs;
  const enter = clamp01(local / entry.enterDurMs);
  let exitP = 0;
  if (entry.exitStartMs !== null) exitP = clamp01((tMs - entry.exitStartMs) / entry.exitDurMs);
  const vis = enter * (1 - exitP);
  const scale = CONFIG.entranceScaleFrom + (1 - CONFIG.entranceScaleFrom) * enter;
  /* The scene layer and the card share one exit transform: a single exit
     progress drives the scene layer's scale, and the card — a child of the
     scene layer — is carried by that same transform while it fades. */
  const sceneScale = entry.exitStartMs !== null ? 1 + (CONFIG.exitScaleTo - 1) * exitP : 1;
  sceneEl.style.transform = "scale(" + sceneScale + ")";
  cardEl.style.transform = "translate(-50%,-50%) scale(" + scale + ")";
  if (CONFIG.entranceMode === "staggered") {
    /* The parent carries the exit fade only; entrances stay with the children,
       so no progress value is applied twice to the same content. */
    cardEl.style.opacity = 1 - exitP;
    lineDivs.forEach((d, li) => {
      const start = entry.enterDurMs + li * CONFIG.lineMs;
      d.style.opacity = clamp01((local - start) / CONFIG.lineFadeMs);
    });
    const chipStart = entry.enterDurMs + lineDivs.length * CONFIG.lineMs;
    chipEl.style.opacity = clamp01((local - chipStart) / CONFIG.chipFadeMs);
    glyphEl.style.opacity = enter;
  } else {
    /* Unit mode: the parent alone carries the entrance/exit opacity;
       the children render at full opacity inside it. */
    cardEl.style.opacity = vis;
    lineDivs.forEach(d => { d.style.opacity = 1; });
    chipEl.style.opacity = 1;
    glyphEl.style.opacity = 1;
  }
}
let startStamp = null, pausedAt = 0, playing = false;
function frame(now) {

  if (t >= effectiveDuration()) { renderAt(effectiveDuration()); playing = false; return; }
  renderAt(t);
  requestAnimationFrame(frame);
}
