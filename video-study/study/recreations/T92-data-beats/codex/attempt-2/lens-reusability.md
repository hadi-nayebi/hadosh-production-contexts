Verdict: **77/100 — strong CONFIG coverage, but production reuse still requires code changes for arbitrary beat order and reliable override validation.**

1. **The beat schema and timing model are substantially reusable.** `CONFIG.beats` supplies each beat’s kind, content, year, slot, clearing/restoration durations, and dialogue cues. `stateAt()` derives entrance and settlement from `graphicEntrance` and `followUp`, while `cycleMs()` sums the configured slots and end hold. `hudYearAt()` uses the current beat’s year, switching to `hud.sceneYear` during restoration. Different claims, sources, years, and schedules can therefore be supplied through CONFIG. The cues are timing metadata; they do not carry or play dialogue text.

2. **Browser chart animation retains a fixed second-beat dependency.** In DOM construction, `chartStages()` reads:
   `const nb = (CFG.beats[1].bars || []).length`
   
   Meanwhile, `buildChart(beat)` constructs bars from the current beat. Moving a chart to index 0, replacing the beat array with a single chart, or configuring chart beats with different series lengths can produce a crash or undefined animation factors. The exported `chartStagesFor(cfg, beat, p)` already uses the supplied beat correctly, but browser drawing does not call it. **Next-attempt cure:** have `drawChart()` use that shared helper with the current beat; verify a single-chart replacement and multiple charts with different bar counts through the actual drawing path.

3. **Value authority and chart series are implemented, with validation gaps.** `hangHeight()` multiplies the parsed percentage by `geom.pxPerPercent`; `buildChart()` places negative values below the beam and positive values above it. `beat.bars` supplies series heights and palette keys. `deriveUnits()` correctly gives a fraction in `beat.value` precedence over `beat.units`. However, `validate()` checks the fallback units rather than the derived units: `"6 in 5"` or `"1 in 0"` can pass with valid fallback units and then render incoherently. Percentage parsing also accepts matching substrings rather than requiring a complete numeric value. **Next-attempt cure:** validate the authoritative parsed representation, including fraction bounds, and require an unambiguous percentage format.

4. **Override merging is useful and explicit.** `deepMerge()` merges nested objects and arrays by index; `{$replace: [...]}` permits shrinking or replacing arrays. This supports both small edits and complete beat/series substitution without code edits. The implementation supports the stated replacement behavior directly; the supplied own-check results remain reported evidence rather than independently reproduced tests.

5. **Validation is neither complete nor reliably diagnostic.** `PROBLEMS` is computed after override, and the final `if (PROBLEMS.length)` branch prevents `showBeat(0)` and animation startup for successfully collected problems. But malformed collection types can throw inside validation: `(cfg.beats || []).forEach(...)` and `(b.bars || []).forEach(...)` assume array methods even after reporting an invalid type. Most geometry, typography, palette, stage, and reveal-window fields are unchecked. DOM setup also dereferences these structures before reaching the diagnostic branch. **Next-attempt cure:** guard collection traversal, validate required render structures and finite/ranged values, and route invalid configurations to a diagnostic before scene construction or unsafe dereferences.

6. **Stagger counts normalize, but layout does not adapt automatically.** `chartStagesFor()` divides reveal spans by configured bar and step counts; the browser helper does the same for steps, subject to the bar-index defect above. Geometry remains configurable through CONFIG, so production can adjust it without code changes. However, increasing counts or percentage magnitude can exceed fixed chart bounds, and longer claims can collide with independently positioned graphics. **Next-attempt cure:** provide fit validation or adaptive layout for series width, signed height, unit-row width, and card/chart clearance.
