## Construction
One self-contained HTML file; DOM/SVG; a CONFIG block at the top of the script carries every shaping value; a single phase resolver returns exactly one state per instant (half-open intervals). Scenes are code-drawn generic silhouettes (a seeded skyline generator plus minimal per-scene furniture) — no specimen media, no traced paths, no external assets; the only URL in the file is the SVG xmlns namespace identifier.
Schedule: per-scene durations in CONFIG (scenes[].ms = 1500 / 1500 / 10000 / 500); the cycle is derived as the sum of scene durations + endHoldMs (500) = 14000 ms. Turn anchors in CONFIG: warmStartMs 4500, duskStartMs 6000; the return instant is derived as the start of the return scene (13000), so the blue register returns together with the final scene by construction. The resolver returns paletteMode blue / warming / dusk plus a warm progress value: during warming the sky color is a continuous per-frame interpolation between the register sky and the dusk sky, and the sun disc's opacity follows the same progress; buildings, lit windows, ground, furniture and HUD keep the register palette in every mode. HUD clock follows the scene (16:00 through the exhibits scene including the turn; 19:00 from the final scene).
Text backing: the HUD header sits on a backing plate (267 px wide) in the warming and dusk modes; the scene label sits on a backing plate (136 px) over the ground strip in every mode. Scene identity is an explicit renderer-type key separate from the display name. At startup the configuration is validated (non-empty scenes, positive durations, ordered turn anchors inside the turn scene's span, return scene immediately after the turn scene, plate geometry inside the stage); a violation renders an explicit error state naming the offending key. Configured text is escaped before entering the SVG markup. The piece self-starts: its own animation loop runs the cycle and wraps without any external caller; render(tMs) is also seekable and pure.
