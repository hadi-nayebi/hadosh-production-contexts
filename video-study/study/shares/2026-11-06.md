# Study share — 2026-11-06 — Topic 9: Academy self-application audit (distributed local working memory)

**What was studied.** One idea the Academy teaches, in its own words, turned back on Archer's own file system: *"The filesystem is the tissue"* — and the sentence that tests it: *"Memory does nothing merely by existing. The harness must discover, select, and reload it at the right time."* Our version of that tissue is the rule that every working folder carries its own AGENTS.md file with the memory for that place, read as a chain from the root down before work starts there.

**What the audit found.** The files exist — a fresh count this morning found every working directory covered (6,238 local-memory files, and a watching hook reporting zero uncovered folders). But existence is only half the Academy's test. The reload half is weak: the last measured sample of real work records showed only 11% naming the chain they were supposed to read, the two most recent daily checks did not measure use at all, and — the sharpest finding — almost none of the standing job instructions actually order the chain read they depend on. One job out of thirty mentions the memory index; none names the chain tool. This study session's own chain read happened because the runtime injected it, not because the job asked for it.

**What changed.** Three fixes, all in the file system itself. The coverage index now qualifies its 100% figure as the existence leg only, and a new section joins it to the latest use evidence, with the gap named where the evidence is stale. The layer-health file corrects its own outdated definitions in place and gains a standing rule: two daily checks in a row without a use measurement is a defect, and the re-measurement is owed before the next coverage headline. And the study job's own template now orders the chain read for its working directory, so the next session reloads its local memory by its own instruction.

**Why it matters for production.** A lesson written in a folder nobody re-reads is not memory — it is storage. Every production lane works out of these local files; if the reload step is not ordered at the point of work and not measured, the lessons paid for in earlier failures quietly stop applying. The joined reporting means the next "coverage is complete" claim carries its use evidence with it, or does not ship.
