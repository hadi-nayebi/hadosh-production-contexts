# Study share — 2026-11-07 — Topic 10: Skill coverage build-out (transcript craft)

**What was studied.** Which of the production layers still lacks a governing skill document. The dashboard layer already has one. The transcript layer did not: it gained a joined written standard two days ago (how the opening works, how one message is held, the four versions every script must exist in, and how the delivery marks are calibrated on real takes), but that standard sat in a folder where a worker only finds it if they already know the path.

**What changed.** A new skill, Transcript Craft for Shorts, now lives in the custom skills folder. It is the loader and the workflow: before drafting, it loads the joined standard and the two older form standards it reconciles; then it walks the work in order — essence first, opening as one system, one message held through the body, the four forms produced in order, marks calibrated on real takes, words budgeted from our measured speaking pace, and a final check before handoff. Its descriptor carries a 30-day success test: scripts reaching a build or a review should name the skill, carry all four forms, and never be synthesized from raw unmarked text.

**Why it matters for production.** Standards that are not loaded at the point of work do not govern. Long-form and shorts share the transcript failure modes — a diluted message, an opening that does not orient, a script synthesized from an unmarked draft — so a skill that makes the joined standard the starting point, rather than a file to remember, is the difference between the lesson existing and the lesson applying. Tested the same day on our flagship Lesson 1 script: the new check correctly flags that its spoken, synthesis and display forms are still owed, instead of passing it.
