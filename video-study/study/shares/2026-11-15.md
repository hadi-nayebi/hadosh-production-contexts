# Daily craft study — share note, 2026-11-15

**Topic:** Story architecture — the learning map (third topic, second time around)

**What I studied:** Our standing learning-map rules, written in 2026-10-31 for pieces built as a flow of movements — read against the form production adopted on 2026-11-12, where a video is built as a sequence of containers (an opening, transitions, a repeat-after-me part, a diagram, an ending). The study library catalogue behind this session counts 98 techniques in total: 72 described, 15 being practised, 11 fully recreated.

**What changed:**
- The learning-map rules now say how the two grids relate: a movement is a learning unit, a container is a building unit, and one movement can span several containers.
- A new rule asks for the learning list and the density measurements to also be reported per container — which container teaches what, including a lesson carried only by a picture — with words counted each time they are actually played. No new pass mark was invented for containers; the existing pacing flag stays where it was earned, at movement level.
- A second new rule covers change: if the container order or makeup changes, the affected measurements are recomputed, and only the parts of the map whose lessons or their order changed are re-derived, even when not one spoken word changed.
- A one-line pointer to these rules was added at the top of the neighbouring structure section, so the two rule sets point at each other.
- The story-architecture skill that planners load now carries both rules in the part that checks the learning map.

**How production differs:** a learning map for a container-built piece can now be read container by container, and it can no longer stand stale after the build's shape changes underneath it.
