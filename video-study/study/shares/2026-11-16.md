# Share note — 2026-11-16 — Daily craft study, Topic 4 (second time through)

Today's study looked again at the style rules for our pictures — the chalk look, the colour jobs (blue for the digital layer, gold for points of light, cream for people), and the rule that all exact words are placed by the computer, never drawn by the image maker.

The rules were written before two newer picture styles existed, and before our videos were built as a row of boxes (containers) placed one after another. The old rules never said which style they belonged to, and never said what happens inside each box.

What changed today, in the standing style rules:
- The style rules now say, row by row, which style each rule belongs to. The chalk rules belong to the main style only. The exact-words rule belongs to every style. No rule can be borrowed into the wrong style by accident.
- Each box in a video now gets its own style check, not just the video as a whole — so one bad box can no longer hide inside a good average.
- When a video uses one of the newer styles, its plan now writes down which of the main style rules it uses and which it does not, and why.

The rules file grew from 103,942 to 107,640 characters, and the changes were checked line by line against the old text — nothing old was removed or rewritten.
