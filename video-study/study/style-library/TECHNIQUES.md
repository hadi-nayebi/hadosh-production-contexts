## Standing decision rule — EASING BY INTENT (landed 2026-11-14, Research Block, motion-graphics craft)

*Every animated element's choreography record names an intent class below and its curve — never a bare `ease`, a copy-pasted `cubic-bezier(...)`, or `linear` for a discrete move. An element with no intent class is UNDECIDED motion: the choreography record is incomplete and the preproduction gate does not pass. Overshoot/anticipation curves are meaning, not decoration.*

| Intent | Curve family | House curve | Rule |
|---|---|---|---|
| ENTER — arrives and ends at rest | decelerate / ease-out (fast start, long settle) | `cubic-bezier(0, 0, 0.2, 1)`; hero/emphasized enter `cubic-bezier(0.05, 0.7, 0.1, 1)` | Focus is the resting point; slow acceleration on entry is a defect |
| EXIT — permanently leaves | accelerate / ease-in | `cubic-bezier(0.4, 0, 1, 1)` | Shorter than the matching enter (Material mobile pair: enter 225 ms / exit 195 ms) |
| EXIT — temporarily leaves, returns from same point | sharp | `cubic-bezier(0.4, 0, 0.6, 1)` | Never use the permanent-exit curve; return uses the ENTER curve |
| MOVE — both endpoints visible on screen | standard / ease-in-out | `cubic-bezier(0.4, 0, 0.2, 1)` | Also use standard when the move pushes other elements (relative movement) |
| CONTINUOUS — measured progress, spinner, playhead | linear only | `linear` | Linear for a discrete enter/exit/move is mechanical and fails |
| EMPHASIS — overshoot (`y>1`) or anticipation dip (`y<0`) | back / spring-like | named per element, no house default | Lawful only when the record names the meaning (playful emphasis, or preparation for a larger action); never a default — overshoot can cross a frame/container edge, so it also needs a containment check at its peak |

Grounding: Material Design, "Movement" (deceleration on entry, acceleration on permanent exit, sharp on temporary exit, standard for on-screen and relative movement, with the 225/195/300 ms mobile durations); Thomas & Johnston, *The Illusion of Life* (1981), via Toon Boom's 12-principles summary (slow in / slow out = easing; anticipation = a preparatory move before a larger action; follow-through = parts settling after the main body stops); FrontendHelpers' cubic-bezier guide, citing Nielsen Norman Group (enter ease-out, exit ease-in and shorter, on-screen move ease-in-out, 100–400 ms for most UI motion; `y>1` = overshoot past the endpoint, `y<0` = anticipation pull-back). Full study: `hidden_files/archer-calendar/research/2026-11-14.md`.
